# 元素と原子

---

## 1. 原子の構成

| 部分 | 内容 | 化学での役割 |
|------|------|--------------|
| 原子核 | 陽子（+）· 中性子（0） | 元素同定 · 同位体 · 質量の大半 |
| 電子 | 負電荷 · 量子化軌道 | 結合 · 周期律 · 反応性 |

- **元素**は陽子数 **原子番号 Z** で区別される。
- **同位体** — 同じ Z、中性子数が異なる（¹²C, ¹³C, ¹⁴C）。
- 電子数 = 陽子数 → 中性原子；不一致 → **イオン**（Na⁺, Cl⁻）。

---

## 2. モルと物質量

| 量 | 定義 |
|----|------|
| モル (mol) | 粒子数 N_A 個に相当する物質量 |
| アボガドロ定数 N_A | ≈ 6.022×10²³ mol⁻¹ |
| 原子量 | ¹²C を 12 とする相対質量（無次元） |
| モル質量 | g/mol（数値 = 原子量） |
| モル濃度 c | mol · L⁻¹（M） |

**例**: Na（Z=11）原子量 22.99 → 1 mol = 22.99 g

---

## 3. 電子配置

### 量子数

| 記号 | 意味 |
|------|------|
| n | 主量子数（殻） |
| l | 方位（s=0, p=1, d=2, f=3） |
| m_l | 磁気量子数 |
| m_s | スピン ±½ |

**パウリ排他原理**: 1 軌道に最大 2 電子（反平行スピン）。

### 軌道容量

s:2 · p:6 · d:10 · f:14

### マデルング規則（充填順）

`	ext
1s → 2s → 2p → 3s → 3p → 4s → 3d → 4p → 5s → 4d → 5p → 6s → 4f → 5d → 6p
`

**代表**: C [He]2s²2p² · Fe [Ar]3d⁶4s² · Cu [Ar]3d¹⁰4s¹（例外: 半充填/全充填 d の安定化）

---

## 4. 周期表と傾向

| 方向 | 原子半径 | イオン化エネルギー IE | 電気陰性度 χ |
|------|----------|----------------------|--------------|
| 周期（左→右） | 減少 | 増加 | 増加 |
| 族（上→下） | 増加 | 減少 | 減少 |

**価電子** — 最外殻電子が族の化学性を決定（アルカリ 1, ハロゲン 7, 希ガス 8）。

---

## 5. イオン

金属は電子を失い **陽イオン**、非金属は得て **陰イオン**。イオン半径は同じ族で電荷が大きいほど小さい傾向（Na⁺ < Mg²⁺）。
