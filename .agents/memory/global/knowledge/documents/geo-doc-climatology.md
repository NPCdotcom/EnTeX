## 気候学とは何か

[気候学](https://ja.wikipedia.org/wiki/%E6%B0%97%E5%80%99%E5%AD%A6)（climatology）は、大気状態の **長期統計**（通常 30 年平均）とその **空間分布 · 変動** を研究する分野。**天気（気象学）** は瞬時 · 短期、**気候** は平均 · 極値 · 確率である。

| 観点 | 内容 |
|------|------|
| **対象** | 気候 normals · 区分 · 変動 |
| **問い** | 通常どうあるか · なぜ地域差があるか |
| **方法** | 観測統計 · 樹輪 · 氷芯 · モデル |
| **成果** | 区分 · 農業 · 都市計画 · 気候変動（気候変動） |

**気候正常値**: 世界気象機関（WMO）では **30 年** の平均を標準とする。

## 気候と天気の違い

| | 天気 | 気候 |
|---|------|------|
| **時間尺度** | 時間〜数日 | 数十年平均 |
| **問い** | 今日雨か | この地域は湿潤か |
| **予測** | NWP（限られた日数） | 統計 · シナリオ |

「気候は何を着るか、天気は今日何を着るか」という比喩がよく使われる。

## 気候を支配する因子

| 因子 | 内容 |
|------|------|
| **緯度** | 太陽高度 · 年較差 |
| **経度 · 大陸性** | 海からの距離 · 季節振幅 |
| **高度** | 気温低下（~0.65 C/100 m） |
| **海流** | 暖流 · 寒流（海洋学） |
| **地形** | 風上 · 風下 · フェーン |
| **植生 · 土壌** | アルベド · 蒸発（土壌学） |

## ケッペンの気候区分

[ケッペン気候区分](https://ja.wikipedia.org/wiki/%E3%82%B1%E3%83%83%E3%83%9A%E3%83%B3%E3%81%AE%E6%B0%97%E5%80%99%E5%8C%BA%E5%88%86): 気温 · 降水に基づく世界標準の区分。

| 記号 | 名称 | 概略 |
|------|------|------|
| **A** | 熱帯 | 最寒月 >= 18 C |
| **B** | 乾燥 | 降水不足 |
| **C** | 温帯 | 最寒月 -3〜18 C、最暖月 > 10 C |
| **D** | 冷帯 | 最寒月 < -3 C、最暖月 > 10 C |
| **E** | 寒帯 | 最暖月 < 10 C |

日本の例: 東京 **Cfa**（温暖湿潤）、札幌 **Dfa**、沖縄 **Am/Af** 等。

## 気候変動と変動

### 5.1 自然変動

| 現象 | 内容 |
|------|------|
| **ENSO** | エルニーニョ · ラニーニャ（太平洋） |
| **PDO / NAO** | 大規模モード |
| **太陽活動** | 長期変動（寄与は限定的） |
| **火山** | エアロゾル冷却（一時的） |

[エルニーニョ](https://ja.wikipedia.org/wiki/%E3%82%A8%E3%83%AB%E3%83%8B%E3%83%BC%E3%83%8B%E3%83%A7%E7%8F%BE%E8%B1%A1): 赤道太平洋の海水温上昇 → 全球天候に影響。

### 5.2 人為気候変動

長期トレンドは **気候変動** で深掘り。気候学 では **気候学が扱う時間尺度** を押さえる。

## 古気候学

[古気候学](https://ja.wikipedia.org/wiki/%E5%8F%A4%E6%B0%97%E5%80%99%E5%AD%A6): 過去の気候を **プロキシ** で復元。

| プロキシ | 内容 |
|----------|------|
| **氷芯** | 古温度 · CO2（雪氷学） |
| **花粉** | 植生 · 湿度 |
| **樹輪** | 年輪幅 · 温度 |
| **沈殿物** | 湖 · 海洋 |

地史学 · 古生物学 古生物学と接続。

---

## 適用範囲と限界

- ケッペン分類 toy は **大区分のみ**（二次区分 Af, Cfa 等は簡略）。
- 乾燥気候（B）の判定は複雑 — 本実験は教育用閾値。
- 人為気候変動の定量は 気候変動 に委ねる。
