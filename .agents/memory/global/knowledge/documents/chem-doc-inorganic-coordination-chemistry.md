# 無機化学と配位化学

---

## 1. 無機化学の範囲

元素・単体・イオン・配位化合物・固体など、**炭素骨格を中心としない** 物質の化学。遷移金属は多彩な酸化数 · 色 · 磁性 · 触媒活性を示す。

---

## 2. 酸化数

| 規則 | 内容 |
|------|------|
| 単体 | 0 |
| 単原子イオン | イオン電荷 |
| O | 通常 −2（過酸化物 −1） |
| H | 通常 +1（金属水素化物 −1） |
| F | −1 |

酸化還元反応の電子数釣り合いに使用。

---

## 3. 配位化合物

**中心金属イオン M** + **配位子 L**（電子対供与）

- **配位数** — 直接結合する配位子数（4, 6 が典型）
- **配位異性** — 配位子の配置が異なる
- **IUPAC 命名** — 配位子名（アルファベット順）+ 金属（酸化数ローマ数字）

例: [Co(NH₃)₆]Cl₃ — 六アンミンコバルト(III)塩化物

---

## 4. 結晶場理論（八面体 O_h）

d 軌道 5 個が配位子電場で分裂:

- **e_g**（上）: d_{z²}, d_{x²−y²}
- **t_{2g}**（下）: d_{xy}, d_{xz}, d_{yz}

分裂エネルギー **10Dq**

| 配置 | CFSE（O_h） |
|------|-------------|
| d³ | −12Dq |
| d⁶ 低スピン | −24Dq |
| d⁶ 高スピン | −4Dq |

**分光化学系列**（配位子の場の強さ）:
I⁻ < Br⁻ < Cl⁻ < F⁻ < H₂O < NH₃ < en < CN⁻ < CO

---

## 5. 固体化学（入口）

| 結晶型 | 結合 | 性質 |
|--------|------|------|
| イオン結晶 | 静電 | 硬い · 融点高 · 水に溶けやすい |
| 金属 | 金属結合 | 導電 · 延性 |
| 共有結晶 | 共有 | 硬い · 融点高 |
| 分子結晶 | 分子間力 | 軟らかい · 融点低 |

---

## 6. 放射化学（入口）

放射性崩壊: α（⁴He 核）· β（電子/陽電子）· γ（電磁波）

**半減期** t_{1/2} — 放射性核種の濃度が半分になる時間

同位体追踪 · 年代測定 · 医療イメージングへの応用。
