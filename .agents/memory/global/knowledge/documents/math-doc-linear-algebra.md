# 線型代数

**出典**: [数学（Wikipedia）](https://ja.wikipedia.org/wiki/数学)「構造 · 線型代数学」

---

## 1. ベクトル

**ベクトル** v ∈ ℝⁿ は n 個の実数成分 (v₁, …, vₙ) の組。

| 演算 | 定義 |
|------|------|
| 和 | (u + v)ᵢ = uᵢ + vᵢ |
| スカラー倍 | (c v)ᵢ = c vᵢ |
| 内積 | u · v = Σ uᵢ vᵢ |
| ノルム | \|v\| = √(v · v) |

**幾何**: ℝ², ℝ³ では向きと大きさ。内積 u·v = \|u\|\|v\| cos θ

---

## 2. 行列

m×n **行列** A = [a_{ij}]: m 行 n 列。

| 演算 | 条件 |
|------|------|
| 和 | 同サイズ |
| 積 AB | A が m×n, B が n×p → 結果 m×p |
| 転置 Aᵀ | 行と列を入替 |

**線形方程式** Ax = b : A ∈ ℝ^{m×n}, x ∈ ℝⁿ, b ∈ ℝᵐ

---

## 3. 行列式（2×2, 3×3）

2×2: det [[a,b],[c,d]] = ad − bc

**意味**: 平行四辺形（2D）· 平行六面体（3D）の **符号付き体積倍率**

**可逆性**: A が可逆 ⇔ det(A) ≠ 0 ⇔ Ax=b が唯一解（正方の場合）

---

## 4. 固有値 · 固有ベクトル

Av = λv を満たすスカラー λ（**固有値**）とベクトル v（**固有ベクトル**）

**2×2 の求め方**: det(A − λI) = 0 を解く

**例**: A = [[2,1],[0,3]]

- 特性方程式: (2−λ)(3−λ) = 0 → λ = 2, 3
- λ=2: v ∝ (1,0) · λ=3: v ∝ (1,1)

**対角化の直観**: 固有ベクトル方向では A は「スカラー倍」だけ → Aⁿ が計算しやすい

---

## 5. ガウス消去（連立一次方程式）

```text
2x + y = 5
x − y = 1
```

拡大係数行列 → 行基本変形 → 後退代入
**解**: x=2, y=1

---

## 6. 演習

### 6.1 内積·角度

u=(1,0), v=(1,1) → u·v=1, \|u\|=1, \|v\|=√2, cos θ = 1/√2 → **θ=45°**

### 6.2 行列積

[[1,2],[0,3]] [[4],[5]] = [[14],[15]]

### 6.3 固有値

上記 A の固有値 **2, 3**（§4）
