# スペクトル理論

## スペクトル

Banach 代数の元 a のスペクトル σ(a) は (a-λI) が可逆でない λ の集合。自己共役作用素のスペクトルは実数。

## 射影値測度（PVM）

単位作用素を射影の可算和で表し、可測関数の作用素値積分を定義する。

## 離散化

グラフラプラシアンの固有値問題は有限次元固有値計算に帰着する。
