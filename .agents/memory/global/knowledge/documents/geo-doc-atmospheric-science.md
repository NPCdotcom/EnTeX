## 大気科学とは何か

[大気科学](https://ja.wikipedia.org/wiki/%E5%A4%A7%E6%B0%97%E7%A7%91%E5%AD%A6)（atmospheric science）は、地球（および惑星）の **大気** の組成 · 構造 · 物理 · 化学 · 力学を研究する分野。**気象学（気象学）** · **気候学（気候学）** の基盤である。

| 観点 | 内容 |
|------|------|
| **対象** | 大気圏全体 |
| **問い** | 大気は何でできているか · どう動くか |
| **方法** | 観測 · ラジオゾンデ · 衛星 · 数値モデル |
| **成果** | 天気予報 · 気候 · 環境 · 航空 |

---

## 大気組成

乾燥空気の体積組成（概略）:

| 成分 | 割合 | 役割 |
|------|------|------|
| **窒素（N2）** | ~78% | 化学的に安定 |
| **酸素（O2）** | ~21% | 呼吸 · 燃焼 |
| **アルゴン（Ar）** | ~0.93% | 不活性 |
| **二酸化炭素（CO2）** | ~0.04%（増加中） | 温室効果ガス |
| **その他** | 微量 | CH4, N2O, O3 等 |

**水蒸気**: 0–4%（場所 · 季節で変動）。天気現象の主役。

## 大気圏の層構造

| 層 | 高度（概略） | 特徴 |
|----|-------------|------|
| **対流圏** | 地表 – 8–15 km | 天気 · 対流 · 温度減率 |
| **成層圏** | 15 – 50 km | オゾン層 · 温度増加 |
| **中間圏** | 50 – 85 km | 温度減少 |
| **熱圏** | 85 km – | 温度増加（分子運動） |

**対流圏界面**: 高度が緯度 · 季節で変化（赤道で高い）。

---

## 気圧と高度

**気圧**: 大気の重量による圧力。海水面 ~1013 hPa。

**気圧高度公式**（概略）:

```text
  p(z) = p0 * exp(-z / H)
```

H ≈ 8.5 km（スケールハイト）。高度が上がると気圧・密度・温度が（対流圏では）低下。

## 温室効果

[温室効果](https://ja.wikipedia.org/wiki/%E6%B8%A9%E5%AE%A4%E5%8A%B9%E6%9E%9C): 温室効果ガスが赤外放射を吸収し、地表温度を上げる自然現象。

| ガス | 寄与 |
|------|------|
| **H2O** | 最大（フィードバック含む） |
| **CO2** | 長期制御 · 人為増加 |
| **CH4** | 強い吸収 · 寿命短め |
| **N2O** | 中程度 |

人為排出による **増強温室効果** は 気候変動 気候変動の中心課題。

## 大気力学（概略）

| 概念 | 内容 |
|------|------|
| **圧力勾配力** | 高圧 → 低圧 |
| **コリオリ力** | 地球自転による偏向 |
| **三胞循環** | Hadley · Ferrel · Polar |
| **ジェット気流** | 中緯度の高速気流 |
| **熱帯収束帯** | 赤道付近の上昇気流 |

詳細な天気システムは **気象学** で扱う。

## 適用範囲と限界

- 気圧公式は **等温 · 乾燥** 近似。対流圏内の実温度構造はより複雑。
- 大気力学は本フェーズでは **概念レベル**。方程式は 気象学 で深化可。
- 組成比は長期変化（特に CO2）している。
