# 数体系と初等代数

**出典**: [数学（Wikipedia）](https://ja.wikipedia.org/wiki/数学)「便宜上の分類 → 量」

---

## 1. 数体系の拡張（ℕ → ℤ → ℚ → ℝ → ℂ）

各拡張は **「解けない問題を解けるようにする」** 動機を持つ。

| 記号 | 名称 | 含むもの | 拡張の動機 |
|------|------|----------|------------|
| **ℕ** | 自然数 | 0,1,2,…（定義により 0 含む） | 計数 |
| **ℤ** | 整数 | …,−1,0,1,… | 減法を常に可能に |
| **ℚ** | 有理数 | p/q（q≠0） | 除法を常に可能に（0除算除く） |
| **ℝ** | 実数 | 数直線上の点（Dedekind 分割 / Cauchy 列で厳密化） | √2 など **無理数** を含む |
| **ℂ** | 複素数 | a + bi | x² + 1 = 0 の解 |

**Fact（代数学の基本定理）**: 複素数上の n 次多項式は n 個の根（重複込み）を持つ → **代数閉体**。
→ で再訪。

### 包含関係

```text
ℕ ⊂ ℤ ⊂ ℚ ⊂ ℝ ⊂ ℂ
```

## 2. 算術の基本性質

### 四則演算（ℝ 上）

| 演算 | 記号 | 逆演算 |
|------|------|--------|
| 加算 | + | 減算 − |
| 乗算 | × | 除算 ÷（0 除算不可） |

**公理の例（実数）**: 加法・乗法の交換·結合·分配、加法単位元 0、乗法単位元 1、加法逆元、乗法逆元（0 以外）。

### 順序（ℝ）

a < b , a ≤ b , 三項律、推移律。
**注意**: ℂ には全順序は定義できない（代数的性質と両立しない）。

## 3. 初等代数

### 恒等式（よく使う）

| 恒等式 | 名前 |
|--------|------|
| (a+b)² = a² + 2ab + b² | 二乗の公式 |
| (a+b)(a−b) = a² − b² | 和と差の積 |
| a³ + b³ = (a+b)(a² − ab + b²) | 立方和 |

### 一次方程式

ax + b = 0 （a≠0）→ x = −b/a

### 二次方程式

ax² + bx + c = 0 （a≠0）

**解の公式**: x = (−b ± √(b² − 4ac)) / (2a)

**判別式** D = b² − 4ac :

| D | 実数解 |
|---|--------|
| D > 0 | 2 個（相異） |
| D = 0 | 1 個（重解） |
| D < 0 | 実数解なし（複素数解あり） |

### 不等式

同次不等式 · 二次不等式は **因数分解 + 符号表** または **判別式** で解く。

---

## 4. 多項式（入口）

- **次数** deg(p): 最高次の係数が非零の指数
- **因数分解**: 多項式を積の形に。例: x² − 5x + 6 = (x−2)(x−3)
- **余りの定理**: p(x) を x−a で割った余り = p(a)

---

## 5. 演習

### 5.1 二次方程式

x² − 5x + 6 = 0
因数分解: (x−2)(x−3)=0 → **x = 2 または 3**

### 5.2 判別式

2x² + 3x + 5 = 0
D = 9 − 40 = −31 < 0 → **実数解なし**（複素数解: x = (−3 ± i√31)/4）

### 5.3 不等式

x² − 5x + 6 < 0
根 x=2,3 の間で負 → **2 < x < 3**

## 1. 代数構造

集合 S に **演算** を定義し、公理を課す。

| 構造 | 演算 | 公理（要約） |
|------|------|--------------|
| **群** (G, ·) | 1 つの二項演算 | 結合 · 単位元 e · 逆元 |
| **環** (R, +, ×) | 2 つの演算 | (R,+) はアーベル群 · 乗法は結合 · 分配法則 |
| **体** (F, +, ×) | 2 つの演算 | 環 + 0≠1 · 乗法逆元（0 以外） |

---

## 2. 群 — 定義と例

(G, ·) が **群** ⇔

1. **結合**: (a·b)·c = a·(b·c)
2. **単位元** e: e·a = a·e = a
3. **逆元** a⁻¹: a·a⁻¹ = e

### 例

| 群 | 集合 | 演算 |
|----|------|------|
| (ℤ, +) | 整数 | 加算 |
| (ℤ/nℤ, +) | {0,…,n−1} | mod n 加算 |
| S₃ | 3 要素の置換 | 合成 |
| 正 n 角形の対称 | 回転·反射 | 合成 |

**位数**: 有限群の要素数 |G|
