# 素粒子 · 核物理

**出典**: [標準模型（Wikipedia）](https://ja.wikipedia.org/wiki/標準模型) · [核物理（Wikipedia）](https://ja.wikipedia.org/wiki/核物理)

## 1. 標準模型（Standard Model）概観

標準模型（SM）は **電弱相互作用** と **強相互作用** を記述するゲージ理論。重力は含まれない。

### 1.1 構成粒子

| 種 | 粒子 | スピン | 電荷 \(Q\) |
|----|------|--------|-----------|
| **クォーク** | u, c, t | 1/2 | +2/3 |
| | d, s, b | 1/2 | −1/3 |
| **レプトン** | e, μ, τ | 1/2 | −1 |
| | ν_e, ν_μ, ν_τ | 1/2 | 0 |
| **ゲージボソン** | γ | 1 | 0 |
| | W±, Z⁰ | 1 | ±1, 0 |
| | g（8 色） | 1 | 0 |
| **ヒッグス** | H⁰ | 0 | 0 |

### 1.2 相互作用

| 力 | 媒介 | 結合定数 · スケール |
|----|------|---------------------|
| 電磁 | γ | \(\alpha \approx 1/137\) |
| 弱 | W±, Z⁰ | \(G_F \approx 1.17\times10^{-5}\,\text{GeV}^{-2}\) |
| 強 | g | \(\alpha_s \sim 0.1\)（\(Q \sim 1\) GeV） |

ラグランジアンは SU(3)_c × SU(2)_L × U(1)_Y ゲージ対称性（自発的対称性の破れ後 U(1)_em）で書ける。

## 2. 保存則

### 2.1 基本保存則

| 保存量 | 条件 · 備考 |
|--------|-------------|
| エネルギー–運動量 | 全相互作用 |
| 電荷 \(Q\) | 全相互作用 |
| バリオン数 \(B\) | 全相互作用（実験的上限厳しい） |
| レプトン数 \(L_e, L_\mu, L_\tau\) | 全相互作用（ neutrino oscillation で flavor 混合） |
| フレーバー | 強 · 電磁のみ（弱で破れうる） |

### 2.2 離散対称性

| 対称性 | 弱相互作用での状態 |
|--------|-------------------|
| C（電荷共役） | 破れ |
| P（空間反転） | 破れ（1957 年 β 崩壊） |
| CP | 破れ（K⁰, B⁰ 系） |
| CPT | 保存（定理） |

### 2.3 ノーターの定理

連続対称性 ↔ 保存量。例: 時間並進不変性 → エネルギー保存。

## 3. 核構造

原子核は **プロトン（p）** と **ニュートン（n）** からなる多フェルミ系。有効相互作用 **Skyrme · Gogny · 密度汎関数理論（DFT）** で束縛エネルギー · 半径 · 準位を計算する。

### 3.1 核力の特徴

| 性質 | 内容 |
|------|------|
| 短距離斥力 | \(r \lesssim 0.5\) fm で急峻 |
| スピン依存 | 三重項 · 単項 |
| テンソル力 | D 波混合 |
| 飽和 | 核内密度 \(\rho_0 \approx 0.16\) fm⁻³ |

### 3.2 シェル模型 · 集体模型

**魔法数**（2, 8, 20, 28, 50, 82, 126）: 閉殻核は特に安定。

**セミ経験的质量公式（Weizsäcker）**:

\[
B = a_V A - a_S A^{2/3} - a_C \frac{Z(Z-1)}{A^{1/3}} - a_A \frac{(N-Z)^2}{A} + \delta(A,Z)
\]

| 項 | 物理 |
|----|------|
| 体積 \(a_V A\) | 核内結合 |
| 表面 \(-a_S A^{2/3}\) | 表面エネルギー |
| クーロン \(-a_C Z(Z-1)/A^{1/3}\) | 陽子反発 |
| 非対称 \(-a_A (N-Z)^2/A\) | ペアリング補正 \(\delta\) |

## 4. 放射性崩壊

### 4.1 崩壊モード

| モード | 過程 | 典型 |
|--------|------|------|
| α 崩壊 | \(^A_Z X \to ^{A-4}_{Z-2} Y + \alpha\) | 重核 |
| β⁻ | \(n \to p + e^- + \bar\nu_e\)（核内） | 中性子過多 |
| β⁺ / EC | \(p \to n + e^+ + \nu_e\) | 陽子過多 |
| 内部転換 | 核励起 → 電子放出 | 同位体 |

### 4.2 崩壊率

**フェルミの黄金律**:

\[
\Gamma = \frac{2\pi}{\hbar} |M_{fi}|^2 \rho(E_f)
\]

\(|M_{fi}|\): 遷移行列要素、\(\rho\): 終状態密度。

**半減期**:

\[
T_{1/2} = \frac{\ln 2}{\Gamma}
\]

β 崩壊の **Kurie  plot**（連続エネルギースペクトル）から **Fermi / Gamow–Teller** 選択則を判定する。

### 4.3 α 崩壊とトンネル効果

Geiger–Nuttall 則:

\[
\ln T_{1/2} = a Z / \sqrt{E_\alpha} - b
\]

\(E_\alpha\): α 粒子エネルギー。Gamow 因子でトンネル確率を記述。

## 5. 核分裂（Fission）

重核（例: \(^{235}\text{U}\)）が中性子捕獲後、変形エネルギー曲面の **鞍点** を越えて 2 つの中程度の核に分裂する。

### 5.1 エネルギー収支

\[
Q = \sum B_\text{products} - B_\text{parent} \approx 200\,\text{MeV}
\]

主に **クーロン斥力** が kinetic energy として解放。追加中性子が **連鎖反応** を可能にする。

| 概念 | 内容 |
|------|------|
| 臨界質量 | 自己持続連鎖に必要な最小量 |
| 増倍率 \(k\) | \(k>1\): 超臨界 |
| 緩速材 | 中性子を熱化（軽水 · 重水 · 黒鉛） |

## 6. 核融合（Fusion）入門

軽核が Coulomb 障壁を越えて結合し、結合エネルギー差が kinetic energy として放出される。

### 6.1 代表反応

| 反応 | \(Q\) (MeV) | 備考 |
|------|-------------|------|
| D + T → α + n | 17.6 | 磁気閉じ込めの主反応 |
| D + D → T + p | 4.0 | |
| D + D → ³He + n | 3.3 | |
| p + p → D + e⁺ + ν_e | 1.44 | 恒星中心（段階的） |

### 6.2 反応率

単位体積あたり反応率:

\[
R = n_1 n_2 \langle \sigma v \rangle
\]

\(\langle \sigma v \rangle\): ** Maxwell 平均断面積**。Gamow ピークで \(T \sim 10^8\) K（恒星）または keV 級（人為プラズマ）で最大。

### 6.3 Lawson 基準

自己加熱点火の必要条件（ざっくり）:

\[
n \tau_E > 10^{20}\,\text{m}^{-3}\,\text{s}, \quad T > 10\,\text{keV}
\]

\( \tau_E \): エネルギー閉じ込め時間。
