# 分析化学

---

## 1. 目的

**分離 · 同定 · 定量** — 試料中の成分を特定し量を決める。

| 分類 | 例 |
|------|-----|
| 古典分析 | 重量 · 容量（滴定） |
| 機器分析 | 分光 · クロマト · 電気化学 |

---

## 2. 滴定

等当点（化学量論的等量点）と終点（指示薬の変化点）を区別。

| 滴定型 | 原理 |
|--------|------|
| 酸塩基 | H⁺ + OH⁻ → H₂O |
| 酸化還元 | 電子授受 |
| 配位 | 金属–配位子 |
| 沈殿 | 難溶性塩生成 |

---

## 3. 分光定量

検量線（校正曲線）: 信号 = k·c + b

**Beer–Lambert**: A = ε l c

**検出限界 LOD** ≈ 3σ_blank / slope

**定量限界 LOQ** ≈ 10σ_blank / slope

---

## 4. 分離法

| 手法 | 分離原理 |
|------|----------|
| 抽出 | 分配係数 |
| 蒸留 | 沸点差 |
| GC | 気相 + 固定相 |
| HPLC | 液相 + 固定相 |
| 電気泳動 | 電荷 · サイズ |

---

## 5. 誤差と品質管理

| 種類 | 原因 |
|------|------|
| 系統誤差 | 装置 · 方法 · 操作バイアス |
| 偶然誤差 | ランダム変動 |

**RSD** = 100 × s / x̄（%）
