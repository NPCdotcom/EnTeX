## 雪氷学とは何か

[雪氷学](https://ja.wikipedia.org/wiki/%E9%9B%AA%E6%B0%B7%E5%AD%A6)（cryosphere science）は、地球上の **雪 · 氷 · 凍土** を対象とする学問。[クリオスフィア](https://ja.wikipedia.org/wiki/%E3%82%AF%E3%83%AA%E3%82%AA%E3%82%B9%E3%83%95%E3%82%A3%E3%82%A2)（雪氷圏）は、気候システムの **感度の高い構成要素** である。

| 観点 | 内容 |
|------|------|
| **対象** | 氷河 · 氷床 · 海氷 · 積雪 · 永久凍土 |
| **問い** | どう増減するか · 気候とどう相互作用するか |
| **方法** | 衛星 · フィールド観測 · 氷芯 · モデル |
| **成果** | 海面上昇 · 水資源 · 気候予測 · 災害 |

## クリオスフィアの構成

| 成分 | 概略 | 体積 · 面積 |
|------|------|-------------|
| **氷床（ice sheet）** | グリーンランド · 南極 | 全球の淡水の大部分 |
| **氷河（glacier）** | 山地 · 極地の流動氷 | 海面上昇に寄与 |
| **海氷** | 海水が凍結 | 北極海中心 · 季節変動大 |
| **積雪** | 季節的雪被 | アルベド · 水資源 |
| **永久凍土** | 2 年以上凍結した地層 | 北半球高緯度の広域 |
| **湖氷 · 河氷** | 淡水の凍結 | 高緯度 · 冬季 |

## 氷河の質量収支

[氷河](https://ja.wikipedia.org/wiki/%E5%86%B0%E6%B2%B3): 雪の蓄積が氷に変換され、重力で **流動** する氷の塊。

```text
  蓄積（accumulation）: 降雪 · 霜付着
       |
  均衡線（ELA）: 蓄積 = 消融
       |
  消融（ablation）: 融解 · 昇華 · 氷山崩壊
```

| 状態 | 条件 |
|------|------|
| **正の収支** | 蓄積 > 消融 → 前進 · 厚くなる |
| **負の収支** | 蓄積 < 消融 → 後退 · 薄くなる |
| **均衡** | 境界が ELA と一致 |

**氷河の種類**: 大陸氷河 · 谷氷河 · 氷帽 · 棚氷（南極）。

## 氷床と海面上昇

| 氷床 | 海面上昇ポテンシャル（概略） |
|------|------------------------------|
| **南極** | ~58 m |
| **グリーンランド** | ~7 m |

氷河 · 氷床の融解は **海面上昇** の主要因（気候変動）。熱膨張も寄与（海洋学）。

---

## 海氷

[海氷](https://ja.wikipedia.org/wiki/%E6%B5%B7%E6%B0%B7): 海水の凍結。塩分は排出され **ブリーン氷** となる。

| 役割 | 内容 |
|------|------|
| **アルベド** | 太陽光反射 → 冷却効果 |
| **生態系** | 北極の基盤 |
| **大気海洋結合** | 熱 · 塩分交換の変調 |

海氷面積の減少は **正のフィードバック**（融解 → 暗い海面 → 吸熱増）を招く。

---

## 永久凍土

[永久凍土](https://ja.wikipedia.org/wiki/%E6%B0%B8%E4%B9%85%E5%87%8D%E5%9C%9F): 2 年以上連続して 0 C 以下の地層。

| 用語 | 内容 |
|------|------|
| **活動層** | 夏に融解する表層 |
| **不活動層** | 年間を通じ凍結 |
| **融解** | 温暖化で炭素 · メタン放出の懸念 |

シベリア · カナダ · アラスカに広域分布。インフラ · 生態系への影響大。

---

## 適用範囲と限界

- 質量収支 toy は **1 次元 · 年間平均** の簡略化。

- 永久凍土の炭素放出量は研究が進行中で不確実性が大きい。
