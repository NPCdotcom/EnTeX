# 化学の全体像

**出典**: [化学（Wikipedia）](https://ja.wikipedia.org/wiki/化学) · [Portal:化学](https://ja.wikipedia.org/wiki/Portal:化学)

---

## 化学とは

化学は **物質の組成 · 構造 · 性質 · 変化** を、主に **原子 · 分子** の階層で説明する自然科学である。物理学（基本原理）· 生物学（生命現象）· 工学（プロセス設計）と密接に接続する。

---

## 三つの分類軸

### 1. 基礎概念（学習の入口）

`	ext
元素と原子 → 分子と化学結合 → 化学反応
`

物質を構成する単位から、結合・構造、そして変換の法則へと積み上げる。

### 2. 主要分野

| 分野 | 主な対象 |
|------|----------|
| 物理化学 | 熱力学 · 量子 · 速度論 · 分光 |
| 無機化学 | 元素 · 錯体 · 固体 |
| 有機化学 | 炭素化合物 · 合成 |
| 高分子化学 | 長鎖分子 · 物性 |
| 生化学 | 生体分子 · 酵素 · 代謝 |
| 分析化学 | 分離 · 同定 · 定量 |
| 応用化学 | 工業プロセス · 材料 |
| 環境化学 | 大気 · 水 · 土壌 · 生態系 |

分野の境界は曖昧であり、触媒・界面・光化学などは複数分野にまたがる。

### 3. 対象スケール（齋藤分類の要約）

| スケール | 例 |
|----------|-----|
| 原子核 | 放射性同位体 · 核反応 |
| 単一分子 | 量子化学 · 分光 |
| 化学反応 | 速度論 · 機構 |
| 分子集合体 | 高分子 · コロイド |
| 表面 · 界面 | 吸着 · 触媒 |
| 環境（巨視） | 大気化学 · 生物地球化学 |

---

## 化学の言語

- **化学式** — 組成の記号表現（H₂O, NaCl）
- **反応式** — 反応物 → 生成物（係数はモル比）
- **構造式** — 結合・立体配置（ルイス · 線角 · 楔型）
- **状態記号** — (s) 固体, (l) 液体, (g) 気体, (aq) 水溶液
