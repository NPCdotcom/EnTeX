## 古生物学とは何か

[古生物学](https://ja.wikipedia.org/wiki/%E5%8F%A4%E7%94%9F%E7%89%A9%E5%AD%A6)（paleontology）は、**地質時代の生物**（古生物）の体制 · 発生 · 生態を研究し、**進化の様式 · 機構** を解明する分野。**古生物を対象とする生物学** である。

| 観点 | 内容 |
|------|------|
| **対象** | 化石 · 古生物 · 生痕 |
| **問い** | 何が · いつ · どこで · どう進化したか |
| **方法** | 比較解剖 · 系統 · 示準化石 · 年代測定 |
| **成果** | 生層序 · 進化史 · 古環境 · 地質時代区分 |

放射年代測定以前は、**示準化石による生層序** が地質学の唯一の時間尺度だった（層序学 · 地史学）。

## 化石とは

[化石](https://ja.wikipedia.org/wiki/%E5%8C%96%E7%9F%B3) = 地質時代の生物の **遺骸** または **活動の痕跡**。古生物としてと堆積物としての **二重の性格** を持つ。

### 3.1 化石化のタイプ（古生物学 概略）

| タイプ | 内容 | 例 |
|--------|------|-----|
| **置換化石** | 鉱物に置換 | 骨 · 貝殻 |
| **印象化石** | 形だけ残る | 葉 · 皮膚 |
| **圧縮化石** | 潰れた記録 | 植物葉 |
| **生痕化石** | 活動の痕跡 | 足跡 · 這い跡 · 巣穴 |
| **体化石** | 生物本体 | 骨格 · 殻 |
| **コピロライト** | 糞化石 | 食性の手がかり |

**タフォノミー**: 腐敗から化石化までの過程。軟組織は通常失われる → 現生生物との **比較解剖**（キュヴィエ）が不可欠。

### 3.2 化石のバイアス

| バイアス | 内容 |
|----------|------|
| **保存バイアス** | 硬い組織が残りやすい |
| **霰石バイアス** | 方解石殻より霰石殻は保存されにくい |
| **再堆積** | 示準化石として無効化 |
| **バイオターベーション** | 擾乱で年代が混濁 |

## 示準化石と示相化石

### 4.1 示準化石（index fossil）

[示準化石](https://ja.wikipedia.org/wiki/%E7%A4%BA%E6%BA%96%E5%8C%96%E7%9F%B3): **年代決定** の指針。

| 条件 | 内容 |
|------|------|
| **現生しない** | 限られた地質時代 |
| **形態が時代で変化** | 種レベルで時代を特定 |
| **広域分布 · 多産** | 相関に使える |
| **再堆積でない** | 原産地の年代を反映 |

| 例（時代） | 化石 |
|------------|------|
| カンブリア紀 | 三葉虫 |
| 古生代–中生代 | アンモナイト |
| 広域（微化石） | 浮遊有孔虫 · 放散虫 |

**微化石** は試料中個体数が多く、示準化石として特に有用。

### 4.2 示相化石（facies fossil）

**環境** を示す化石（水深 · 塩分 · 酸素等）。示準化石とは目的が異なる。

## 年代推定の手法

| 手法 | 対象 | 接続 |
|------|------|------|
| **示準化石** | 相対年代 | 層序学 層序 |
| **放射年代** | 絶対年代 | 地球化学 |
| **14C** | 有機物 · ~5 万年以内 | 第四紀 |
| **ESR · ラセミ化** | 補助年代 | — |
| **分子化石** | 生物マーカー | 微古生物 |

## 進化と古生物学

- 現生生物は進化の **一断面** のみ。古生物は **時間の流れ** の中で観察できる。
- **比較解剖学**（キュヴィエ）: 一部から全体を推定。
- 進化論の源流の一つは **化石研究**（ラマルク · ダーウィン）。
- **系統**（phylogeny）: 現生 + 化石で系統樹を構築（古生物学 深化 · 雪氷学 相当は生物学側）。

## 大量絶滅

[大量絶滅](https://ja.wikipedia.org/wiki/%E5%A4%A7%E9%87%8F%E7%B5%B6%E6%BB%85): 短期間に生物多様性が急減。顕生代の **紀境界** の多くと対応。

| イベント | 境界 | 年代 (Ma) | 規模（概算） |
|----------|------|-----------|--------------|
| オルドビス紀末 | — | ~444 | 種の ~85% |
| **ペルム紀末** | **P-T** | ~252 | **最大**（地球史） |
| 三畳紀末 | — | ~201 | 海洋生物科の減少 |
| **白亜紀末** | **K-Pg** | ~66 | 非鳥類恐竜等 |

### 7.1 P-T 境界

[P-T境界](https://ja.wikipedia.org/wiki/P-T%E5%A2%83%E7%95%8C): ペルム紀末の大量絶滅。アンモナイト族の 97% 属絶滅。海退 · パンゲア · シベリア・トラップ等の仮説。

### 7.2 K-Pg 境界

[K-Pg境界](https://ja.wikipedia.org/wiki/K-Pg%E5%A2%83%E7%95%8C): 白亜紀末。イリジウム異常 · **チクシュルーブ・クレーター**（隕石衝突）。デカン・トラップ（火山）との複合説も議論中。

境界は **GSSP**（全球層型断面・地点）で客観的に定義（地質時代）。

## 適用範囲と限界

- 化石記録は **不完全**（保存 · 発見バイアス）。全生物史は復元できない。
- 大量絶滅の **単一原因説** は多くが議論中（複合要因が主流）。
- K-Pg の「数年で完了」等の時間スケールは研究で更新されうる。
