# 数学的証明・集合論・論理

**出典**: [数学（Wikipedia）](https://ja.wikipedia.org/wiki/数学)「基礎と方法」「基礎付け」

---

## 1. 数学的証明の技法

数学的証明 = 公理 · 定義 · 既知の定理から、論理規則だけで **「常に真」** であることを示す手続き。

| 技法 | 概要 | 典型例 |
|------|------|--------|
| **直接証明** | 仮定 → 論理的操作 → 結論 | 「偶数 n なら n² も偶数」 |
| **対偶** | 「P ⇒ Q」と同値な「¬Q ⇒ ¬P」を証明 | 逆否命题の利用 |
| **背理法** | 結論の否定を仮定し矛盾を導く | √2 が無理であること |
| **数学的帰納法** | 基底 + 帰納段階で ∀n P(n) | 1+…+n = n(n+1)/2 |
| **場合分け** | 互いに排他的なケースを網羅 | 奇偶 · 符号 |

**Fact**: 古代は例示で十分とされていたが、ギリシア以降 **普遍性** を持つ定理 + 証明が標準になった（[数学史](https://ja.wikipedia.org/wiki/数学史)）。

## 2. 集合（素朴集合論）

19 世紀以降、数学の言語として **集合論** が発展。本節では **素朴集合論**（直観的操作）から始め、パラドックス（ラッセルのパラドックス等）は後の章で扱う。

### 記法

| 記号 | 意味 |
|------|------|
| ∈ | 属する |
| ∉ | 属さない |
| ⊂ , ⊆ | 部分集合（真 · 含む） |
| ∪ | 和集合 |
| ∩ | 共通部分 |
| \ または − | 差集合 |
| ∅ | 空集合 |
| \|A\| | 要素の個数（有限のとき） |
| 𝒫(A) | A の冪集合（部分集合全体） |

### 基本法則（検証済み）

- **交換**: A ∪ B = B ∪ A , A ∩ B = B ∩ A
- **結合**: (A ∪ B) ∪ C = A ∪ (B ∪ C)
- **分配**: A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C)
- **ド・モルガン**: (A ∪ B)ᶜ = Aᶜ ∩ Bᶜ （全体集合 U 上の補集合）

### 関係と写像

- **関係** R ⊆ A × B : (a,b) ∈ R で「a と b が関係 R にある」
- **写像** f: A → B : 各 a ∈ A に **唯一の** f(a) ∈ B
- **全射** : ∀b ∈ B, ∃a, f(a)=b
- **単射** : f(a)=f(a') ⇒ a=a'
- **全単射（双射）** : 全射かつ単射

## 3. 論理（命題 · 述語）

| 記号 | 意味 |
|------|------|
| ¬P | P の否定 |
| P ∧ Q | P かつ Q |
| P ∨ Q | P または Q |
| P ⇒ Q | P ならば Q（含意） |
| P ⇔ Q | P と Q は同値 |
| ∀x P(x) | 任意の x について P(x) |
| ∃x P(x) | P(x) となる x が存在 |

### 重要な同値

- **対偶**: (P ⇒ Q) ⇔ (¬Q ⇒ ¬P)
- **ド・モルガン（論理）**: ¬(P ∧ Q) ⇔ (¬P ∨ ¬Q)
- **量化子の否定**: ¬(∀x P(x)) ⇔ ∃x ¬P(x)

## 4. よく使う数学記号（抜粋）

| 記号 | 読み | 用途 |
|------|------|------|
| ℕ, ℤ, ℚ, ℝ, ℂ | 自然 · 整数 · 有理 · 実 · 複素 | 数体系 |
| ∈, ⊂, ∪, ∩ | — | 集合 |
| ∀, ∃ | 任意 · 存在 | 述語論理 |
| ⇒, ⇔ | ならば · 同値 | 含意 |
| ∑, ∏ | シグマ · パイ | 和 · 積 |
| ∞ | 無限大 | 極限の入口 |
| ≈, ≡ | 近似 · 同値（文脈依存） | 等式の変種 |
| ∴, ∵ | ゆえに · なぜなら | 証明の接続 |
