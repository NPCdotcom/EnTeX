## 地震学とは何か

[地震学](https://ja.wikipedia.org/wiki/%E5%9C%B0%E9%9C%87%E5%AD%A6)（seismology）は、**地震** · **地震波** · **地球内部構造** · **断層活動** を研究する分野。地球物理学（地球物理学）の中核で、**内部探査** と **災害科学** の両方に資する。

| 観点 | 内容 |
|------|------|
| **対象** | 地震波 · 震源 · 断層 |
| **問い** | いつどこで起きるか · 内部は何でできているか |
| **方法** | 地震計 · 観測網 · 波形解析 |
| **成果** | 震源決定 · 層構造 · ハザード評価 |

## 地震の基本

| 用語 | 定義 |
|------|------|
| **震源（hypocenter）** | 地震が発生した地下の点 |
| **震央（epicenter）** | 震源の真上の地表点 |
| **断層** | 岩石の破壊面（構造地質学） |
| **弾性リバウンド** | 歪み蓄積 → 破壊 → 跳ね返り |

**地震の原因**: プレート境界の摩擦 · 断層のずれ · 火山活動 · 人為（誘発地震）等。

## 地震波

[地震波](https://ja.wikipedia.org/wiki/%E5%9C%B0%E9%9C%87%E6%B3%A2): 弾性体を伝わる波。

### 3.1 体波（地球内部を伝播）

| 波 | 名称 | 速度 | 振動 | 通過 |
|----|------|------|------|------|
| **P波** | 縦波 · 初波 | 速い（~6–14 km/s） | 圧縮 · 膨張 | 固体 · 液体 · 気体 |
| **S波** | 横波 · 遅波 | 遅い（~3–8 km/s） | 横揺れ | **固体のみ** |

**外核で S波陰影**: S波が伝わらない帯 → 外核は液体（地球物理学）。

### 3.2 表面波

| 波 | 特徴 |
|----|------|
| **Rayleigh波** | 縦 · 横成分、地表付近で振幅大 |
| **Love波** | 横揺れのみ、地殻内を伝播 |

表面波は **破壊力が大きい** → 建物被害の主因。

### 3.3 速度と内部構造

P波速度の **不連続面**（モホ面 · 410 km · 660 km · 核境界）が層境界を示す。

## マグニチュードと震度

### 4.1 マグニチュード（規模）

[マグニチュード](https://ja.wikipedia.org/wiki/%E3%83%9E%E3%82%B0%E3%83%8B%E3%83%81%E3%83%A5%E3%83%BC%E3%83%89): 地震の **エネルギー規模**（対数尺度）。

| 尺度 | 内容 |
|------|------|
| **ML** | 局所マグニチュード（古い方式） |
| **Mw** | モーメントマグニチュード（大規模地震で標準） |
| **Mj** | 気象庁マグニチュード（日本） |

**Mw** は断層面積 × すべり量 × 剛性から算出。**1 段階差 ≈ 32 倍エネルギー**（Mw 尺度）。

### 4.2 震度（影響）

[震度](https://ja.wikipedia.org/wiki/%E9%9C%87%E5%BA%A6%E9%9A%8E%E7%B4%9A): 地点ごとの **揺れの強さ**（規模ではない）。

| 震度（気象庁） | 体感 |
|----------------|------|
| 0–2 | ほとんど感じない〜少数が感じる |
| 3–4 | 室内で感じる〜机が揺れる |
| 5弱–5強 | 不安定な物が倒れる〜壁の損傷 |
| 6弱–6強 | 家具転倒〜建物倒壊も |
| 7 | 立っていられない · 広範な倒壊 |

同じ地震でも **震源距離 · 地盤 · 建物** で震度は変わる。

## 震源決定

**到達時間法**: 複数観測点の P波（S波）到達時刻から震央を三角測量。

```text
  各観測点: 震源距離 = 波速 x 伝播時間
  3 点以上で円の交点 -> 震央
```

**震源メカニズム**: 初動（上下）の分布から断層の運動方向を推定。

## プレートテクトニクスと地震

| 境界 | 地震タイプ | 深度 |
|------|-----------|------|
| **拡大境界** | 浅い · 小〜中規模が多い | 浅部 |
| **収束境界** | 浅い〜深い（ベニオフ帯） | 0–700 km |
| **横ずれ境界** | 浅い · 大規模も | 浅部 |

日本は **4 プレート交差** → 地震 · 火山が頻繁（プレートテクトニクス · 自然災害）。

| 要素 | 内容 |

| **地震計ネットワーク** | 全国常時観測 |

| **活断層調査** | 長期リスク評価 |
| **耐震設計** | 建築基準 · 液状化対策 |

## 適用範囲と限界

- 到達時間 toy は **均一速度 · 平坦地球** を仮定。実際は速度構造が複雑。
- マグニチュード尺度は **定義が複数** あり、混同に注意。
- 地震予知（時刻 · 場所の確定予測）は現状 **実用的には困難**。
