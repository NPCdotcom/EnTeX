# 数値解析

**出典**: [数学（Wikipedia）](https://ja.wikipedia.org/wiki/数学)「計算機 · 数値解析 · 計算科学」

---

## 1. 数値解析とは

**数値解析** = 数学問題を **有限精度の計算機** 上で近似求解する方法論。

| 観点 | 解析解 | 数値解 |
|------|--------|--------|
| 正確さ | 記号的に厳密（存在すれば） | 近似 · 誤差を伴う |
| 適用 | 特殊な形に限る | 広い問題クラス |
| 誤差 | なし | 丸め · 打切り |

** の到達目標**: 同一問題を解析解と数値解で比較し、誤差の由来を説明できる。

---

## 2. 浮動小数と丸め誤差

IEEE 754 **倍精度** (float64): 約 15–16 有効桁。

| 現象 | 例 | 対策 |
|------|-----|------|
| **丸め誤差** | 0.1 + 0.2 ≠ 0.3 | 許容誤差比較 `isclose` |
| **桁落ち** | 大きい数 + 小さい数 | 式変形 · 高精度 |
| **相消** | √(x+1) − √x を x 大で | 有理化 · 級数 |

**安定性**: 入力の微小扰動が出力を大きく変えない算法を **数値的に安定** と呼ぶ。

---

## 3. 数値線形代数

Ax = b（A ∈ ℝ^{n×n}）

| 手法 | 内容 | 備考 |
|------|------|------|
| **ガウス消去** | O(n³) · で実装済 | ピボット選択で安定化 |
| **LU 分解** | A = LU | 同じ A で複数 b |
| **反復法** | Jacobi · Gauss-Seidel | 疎行列 · 大規模 |

**条件数** κ(A) = \|A\| \|A⁻¹\|: 大きいと誤差が増幅（ **悪条件** ）

---

## 4. 数値積分

∫_a^b f(x) dx の近似:

| 公式 | 次数 | 式 |
|------|------|-----|
| **台形則** | 1 次 | h/2 · (f(a) + f(b)) |
| ** Simpson** | 3 次 | h/6 · (f(a) + 4f(m) + f(b)) |
| **リーマン和** | — | `derivative_integral.py` |

**打切り誤差**: 区間分割 n を増やすと精度向上（滑らかな f）

---

## 5. 常微分方程式（数値解法）

y' = f(t, y), y(t₀) = y₀

| 手法 | 次数 | 備考 |
|------|------|------|
| **Euler** | 1 | 実装 · 簡単 · 精度低 |
| **Heun** | 2 | 予測-修正 |
| **Runge-Kutta 4 (RK4)** | 4 | 実用標準 |

### RK4（1 ステップ）

```text
k1 = f(t, y)
k2 = f(t + h/2, y + h·k1/2)
k3 = f(t + h/2, y + h·k2/2)
k4 = f(t + h, y + h·k3)
y_{n+1} = y_n + h/6 · (k1 + 2k2 + 2k3 + k4)
```

**例** y' = −y, y(0)=1 → 厳密解 y = e^{−t}

## 7. 解析解 vs 数値解（統合例）

### 7.1 定積分 ∫₀¹ x² dx

| 方法 | 結果 |
|------|------|
| 解析 | [x³/3]₀¹ = **1/3** |
| Simpson n=10 | ≈ 0.333333 |
| リーマン n=10000 | ≈ 0.3333333325 |

### 7.2 ODE y' = −y, y(0)=1 at t=2

| 方法 | h=0.1 | 誤差 |
|------|-------|------|
| 厳密 | 0.135335 | — |
| Euler | 0.121577 | ~1.4×10⁻² |
| RK4 | 0.135335 | ~10⁻⁷ 程度 |

## — 数理モデル

**数理モデル** = 現象を数学的対象（方程式 · 確率 · 最適化）で **理想化** したもの。

| 段階 | 内容 |
|------|------|
| 1. 仮定 | 何を無視するか（摩擦なし · 独立同分布 等） |
| 2. 定式化 | 微分方程式 · 確率モデル · 效用関数 |
| 3. 推定 | データからパラメータ（最小二乗 · MLE） |
| 4. 検証 | 予測 vs 観測 · 残差分析 |

**注意**: モデルと現実の **ずれ** は常に存在（Wikipedia「数理モデル」）。

### 最小二乗法（線形回帰）

データ (x_i, y_i) に直線 y = ax + b を当てはめる:

a = Σ(x_i−x̄)(y_i−ȳ) / Σ(x_i−x̄)²
b = ȳ − a x̄

## — ゲーム理論（入口）

**ゲーム** = プレイヤー · 戦略 · 利得 の組。

| 概念 | 内容 |
|------|------|
| **戦略** | 各プレイヤーの選択 |
| **利得** | 結果に対する評価 |
| **最適反応** | 相手戦略固定下で自分の利得最大化 |
| **ナッシュ均衡** | 誰も一方的に戦略変更しない状態 |

### 囚人のジレンマ（利得例）

| | 相手:協力 | 相手:裏切 |
|--|-----------|-----------|
| **自分:協力** | (−1,−1) | (−3, 0) |
| **自分:裏切** | (0,−3) | (−2,−2) |

**ナッシュ均衡**: **（裏切, 裏切）** — 各者が裏切るのが最適反応
