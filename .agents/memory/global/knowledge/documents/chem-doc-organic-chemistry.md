# 有機化学

---

## 1. 定義と範囲

**有機化学** — 炭素化合物（および有機金属 · 有機ハロゲン等）の構造 · 性質 · 反応 · 合成。

---

## 2. IUPAC 命名

1. 最長炭素鎖を選ぶ（主鎖）
2. 置換基に番号を付ける（最小番号の法則）
3. 置換基をアルファベット順に列記
4. 主官能基で后缀を決める

| 官能基 | 后缀/接頭 |
|--------|-----------|
| アルカン | -ane |
| アルケン | -ene |
| アルコール | -ol |
| アルデヒド | -al |
| ケトン | -one |
| カルボン酸 | -oic acid |
| エステル | -oate |
| アミン | -amine |

---

## 3. 電子論と芳香族

- **誘導効果 I** — σ 結合による電子供与/吸引（+I, −I）
- **共役効果 M** — π 系との相互作用（+M, −M）
- **芳香族** — Hückel 規則: 閉じた共役環で 4n+2 π 電子（ベンゼン 6）

---

| 型 | 条件 |

| E1 | カチオン中間体 |

### 付加反応
アルケンへの HX, X₂, H₂O 等の付加

---

## 5. 立体化学

- **シス/トランス** — 二重結合または環上の配置
- **R/S 命名** — Cahn–Ingold–Prelog 優先順位
- **キラル** — 鏡像非重合物；対映体は光学活性

---

## 6. 有機合成の戦略

官能基変換 · 保護基 · 選択性（化学/区域/立体）· 逆合成分析（目標分子から前駆体へ遡る）。
