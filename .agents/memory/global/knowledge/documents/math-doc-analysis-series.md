# 級数と解析入門

---

## 1. 数列と級数

**数列** {a_n}: n = 1, 2, 3, … に対応する値の列

**級数** Σ_{n=1}^∞ a_n = a_1 + a_2 + … （部分和 S_N = Σ_{n=1}^N a_n の極限）

| 級数 | 収束条件 | 和 |
|------|----------|-----|
| 等比級数 Σ ar^n | \|r\| < 1 | a/(1−r) |
| 調和級数 Σ 1/n | **発散** | — |
| Σ 1/n² | 収束 | π²/6（Basel 問題） |

---

## 2. テイラー級数 · マクローリン級数

x=0 周りのテイラー = **マクローリン級数**:

f(x) = Σ_{n=0}^∞ [f^{(n)}(0)/n!] x^n

### 主要な展開

| f(x) | 級数 |
|------|------|
| e^x | 1 + x + x²/2! + x³/3! + … |
| sin x | x − x³/3! + x⁵/5! − … |
| cos x | 1 − x²/2! + x⁴/4! − … |
| ln(1+x) | x − x²/2 + x³/3 − … （\|x\|≤1, x≠−1） |
| 1/(1−x) | 1 + x + x² + … （\|x\|<1） |

**用途**: 関数の近似 · 数値計算 · 解析学の深化（: 複素解析）

---

## 3. 収束の直観

- **点wise 収束**: 各 x で部分和が極限に近づく
- **一様収束**: 全体で同時に近づく（より強い条件）
- **半径 of 収束**（冪級数）: 級数が収束する |x| の範囲

本節では **有限項での近似** まで。厳密な収束判定は後の章で。

---

## 4. 演習

e^x を x=0 で 3 次まで: **1 + x + x²/2 + x³/6**

x=0.1 で: 真値 e^0.1 ≈ 1.10517, 近似 1 + 0.1 + 0.005 + 0.000167 ≈ **1.10517**（良好）
