## 測地学とは何か

[測地学](https://ja.wikipedia.org/wiki/%E6%B8%AC%E5%9C%B0%E5%AD%A6)（geodesy）は、地球の **形状 · 重力場 · 回転** を精密に測定し、**座標系 · 高さ · 位置** の基準を定める学問。地図 · GIS · GPS · 地殻変動観測の基盤である。

| 観点 | 内容 |
|------|------|
| **対象** | 地球形状 · 重力 · 座標 |
| **問い** | 地球は何形か · どこにあるか · どう動くか |
| **方法** | 衛星レーザー · GPS/GNSS · 重力測定 |
| **成果** | 座標系 · 地図 · プレート運動 · 海面上昇 |

---

## 地球の形状

| 概念 | 内容 |
|------|------|
| **真球** | 近似（極半径と赤道半径がわずかに異なる） |
| **回転楕円体** | 測地の標準モデル（扁平率 f） |
| **ジオイド** | 重力ポテンシャル等値面（平均海面に近い） |
| **地形** | 楕円体表面からの起伏 |

**楕円体高（h）**: GPS が直接与える高さ。  
**正高（標高）**: ジオイドからの高さ（国土地理院の標高に近い）。

## WGS84 楕円体

[WGS84](https://ja.wikipedia.org/wiki/WGS84): GPS が用いる世界測地系。

| パラメータ | 値（概略） |
|------------|-----------|
| **赤道半径 a** | 6,378,137 m |
| **極半径 b** | 6,356,752 m |
| **扁平率 f** | 1/298.257223563 |
| **第一離心率² e²** | ~0.006694 |

日本の旧測地系（東京測地系）から **JGD2011 / ITRF** への移行は座標に数 m の差を生む。

---

## 座標系

| 系 | 内容 | 用途 |
|----|------|------|
| **地理座標** | 緯度 phi · 経度 lambda | GPS · 全球 |
| **地心直交座標** | X, Y, Z | 衛星軌道 · 変換 |
| **投影座標** | UTM · 平面直角座標 | 地図 · 測量 |

### 4.1 UTM（横メルカトル）

地球を **6 度帯** に分割。日本は主に **ゾーン 53–54**（EPSG:32654 等）。

### 4.2 日本平面直角座標系

19 系に分かれ、各都府県で高精度測量に用いる。

## GPS / GNSS

[GNSS](https://ja.wikipedia.org/wiki/%E5%85%A8%E5%9C%B0%E6%B8%AC%E4%BD%8D%E3%82%B7%E3%82%B9%E3%83%86%E3%83%A0): 衛星からの距離測定で位置を決定。

| 方式 | 精度（概略） |
|------|-------------|
| **単独測位** | 数 m |
| **ディファレンシャル（RTK）** | cm 級 |
| **PPP** | cm〜dm 級 |

**用途**: ナビ · 地図 · 地殻変動 · 火山監視（火山学, 地震学）。

---

## 地殻変動

| 現象 | 速度（概略） |
|------|-------------|
| **プレート運動** | 数 cm/年 |
| **ポストシズミック** | 地震後のゆっくりしたずれ |
| **火山膨張** | 噴火前の隆起 |
| **グローバル海面上昇** | mm/年（ジオイド基準） |

GNSS 連続観測点で **日本列島の水平変位** をモニタリング。

## 測地と地学の接続

| 分野 | 接続 |
|------|------|
| **自然地理学 自然地理** | GIS · 地図 |
| **地質調査** | 地質図の位置精度 |
| **構造地質学 構造** | 断層変位測定 |
| **地震学 地震** | 同震変位 |
| **プレートテクトニクス プレート** | 速度場 |

---

## 適用範囲と限界

- 距離計算は **球面近似（ハバースine）** 。精密測量は楕円体上の測地線を用いる。
- ジオイド高の詳細は各国のジオイドモデルに依存。
- 座標系変換の厳密式は本フェーズでは省略。
