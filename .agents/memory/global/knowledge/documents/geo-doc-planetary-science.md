## 惑星科学とは何か

[惑星科学](https://ja.wikipedia.org/wiki/%E6%83%91%E6%98%9F%E7%A7%91%E5%AD%A6)（planetary science）は、**惑星 · 衛星 · 小天体** の起源 · 進化 · 構造 · 大気 · 表面を研究する分野。地球科学を **宇宙スケール** に拡張し、[比較惑星学](https://ja.wikipedia.org/wiki/%E6%AF%94%E8%BC%83%E6%83%91%E6%98%9F%E5%AD%A6)で地球の特殊性 · 普遍性を問う。

| 観点 | 内容 |
|------|------|
| **対象** | 岩石惑星 · ガス惑星 · 氷天体 · 衛星 |
| **問い** | どう形成したか · なぜ地球だけ生命か |
| **方法** | 望遠鏡 · 探査機 · 隕石 · シミュレーション |
| **成果** | 太陽系史 · 地球システム理解 · 系外惑星 |

地質学 · … · 陸水学 の地球中心の知見を **他天体へ転用 · 検証** する統合フェーズ。

## 太陽系の構成

```text
  太陽
    |
    +-- 岩石惑星 (Mercury - Mars)
    +-- 小惑星帯
    +-- ガス・氷巨人 (Jupiter - Neptune)
    +-- カイパー帯 · オールトの雲
```

| 区分 | 代表 | 特徴 |
|------|------|------|
| **岩石惑星** | 地球 · 火星 | シリケート地殻 · 鉄核 |
| **ガス巨人** | 木星 · 土星 | H/He 主体 |
| **氷巨人** | 天王星 · 海王星 | H/He + 水 · メタン · アンモニア |
| **衛星** | 月 · エウロパ · タイタン | 潮汐 · 内部海 · 大気 |

## 惑星パラメータ

基本観測量から **派生量** を計算するのが比較惑星学の出発点。

| パラメータ | 記号 | 意味 |
|------------|------|------|
| **質量** | M | 重力 · 保持能力 |
| **半径** | R | 体積 · 表面重力 |
| **平均密度** | ρ = M/V | 組成の指標 |
| **表面重力** | g = GM/R² | 大気保持 · 地形 |
| **脱出速度** | v_esc = √(2gR) | 大気逸散の閾値 |

```text
  低密度 + 大半径 -> ガス巨人
  高密度 + 小半径 -> 鉄核の大きい岩石惑星
```

## 定量的モデル（惑星パラメータ）

G = 6.674e-11 m3 kg-1 s-2

| 量 | 式 |
|----|-----|
| 密度 | rho = M / (4/3 pi R^3) |
| 表面重力 | g = GM/R^2 |
| 脱出速度 | v_esc = sqrt(2GM/R) |

**地球**: rho ~5514 kg/m3, g ~9.82 m/s2, v_esc ~11.2 km/s
**火星**: g ~3.7 m/s2（大気保持弱い）
**木星**: rho ~1330 kg/m3（ガス主体）

**ハビタブルゾーン（経験式 toy）**: 太陽型恒星で内側 ~0.95 AU、外側 ~1.37 AU。地球 (1 AU) は帯内。
