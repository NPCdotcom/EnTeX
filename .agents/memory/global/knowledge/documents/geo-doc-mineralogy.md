## 鉱物学とは何か

[鉱物学](https://ja.wikipedia.org/wiki/%E9%89%A2%E7%89%A9%E5%AD%A6)（mineralogy）は、**鉱物**の組成 · 結晶構造 · 物理 · 化学性質 · 成因を研究する分野。**岩石学（岩石学）** の基盤であり、**鉱床学（鉱床学）** · **宝石学** と接続する。

| 観点 | 内容 |
|------|------|
| **対象** | 天然の無機固体（結晶質） |
| **問い** | 何の化学組成か · どう結晶化したか |
| **方法** | X 線回折 · 薄片 · 化学分析 · 硬度試験 |
| **成果** | 鉱物同定 · 岩石成因 · 資源評価 |

### 1.1 鉱物の定義（IMA 慣行）

| 条件 | 内容 |
|------|------|
| **天然起源** | 人工合成は別扱い |
| **無機** | 有機物は別分野 |
| **固体** | 常温常圧で固体 |
| **決まった化学組成** | 固溶体 · 系列を含む |
| **結晶構造** | 規則的な原子配列（非晶質ガラスは岩石成分だが鉱物ではない） |

## 結晶系（7 系）

[結晶系](https://ja.wikipedia.org/wiki/%E7%B5%90%E6%99%B6%E7%B3%BB): 結晶の **対称性** に基づく分類。32 の結晶クラスが 7 系にまとまる。

| 結晶系 | 軸の関係 | 代表鉱物 |
|--------|----------|----------|
| **等軸晶系** | a=b=c, 90° | ガーネット · 方鉛鉱 · 塩 |
| **正方晶系** | a=b≠c, 90° | ジルコン · ルチル |
| **六方晶系** | a=b≠c, 120° | 石英 · 方解石 · 緑柱石 |
| **三方晶系** | （六方の一部） | コランダム · 菱鉄鉱 |
| **斜方晶系** | a≠b≠c, 90° | オリビン · トパーズ |
| **単斜晶系** | 1 軸が斜交 | 長石 · 輝石 · 雲母 |
| **三斜晶系** | 3 軸すべて斜交 | カリ長石（微斜長石） · 青銅鉱 |

**結晶習性**: 結晶の外形（柱状 · 板状 · 粒状）は内部構造の反映。

## 鉱物の分類

### 3.1 化学組成による大分類

| クラス | 組成 | 例 |
|--------|------|-----|
| **ネイティブ元素** | 単元素 | 金 · 銅 · ダイヤモンド（C） |
| **硫化物 · 硫化塩化物** | S 主体 | 黄鉄鉱 · 方鉛鉱 · 閃亜鉛鉱 |
| **酸化物 · 水酸化物** | O 主体 | ヘマタイト · 磁鉄鉱 · ルチル |
| **炭酸塩** | CO3 | 方解石 · ドロマイト |
| **ハロゲン化物** | F, Cl | フッ石 |
| **硫酸塩** | SO4 | 石膏 · 重晶石 |
| **リン酸塩** | PO4 | アパタイト |
| **シリケート** | SiO4 テトラヘドロン | 石英 · 長石 · 雲母 · 輝石 |

**地殻の約 90%** はシリケート鉱物（岩石学 火成岩 · 変成岩の主成分）。

### 3.2 シリケートの構造分類

| 構造 | Si:O 比 | 例 |
|------|---------|-----|
| **孤立テトラヘドロン** | 1:4 | オリビン · ジルコン |
| **連結テトラヘドロン** | 1:3 | エピドート |
| **環状** | 1:3 | ベリル · トルマリン |
| **単鎖** | 1:3 | 輝石 |
| **複鎖** | 4:11 | 角閃石 |
| **板状** | 4:10 | 雲母 · 粘土鉱物 |
| **架状** | 1:2 | 石英 · 長石 · フェルドパス |

架状シリケート（長石 · 石英）が地殻量の大部分を占める。

## 物理性質（同定の手がかり）

| 性質 | 内容 | 野外での使い方 |
|------|------|----------------|
| **硬度** | モース硬度 1–10 | 爪 · コイン · 鋼で試す |
| **劈開 · 割理** | 結晶構造に沿った割れ方 | 雲母は板状 · 方解石は 3 方向 |
| **比重** | 密度の目安 | 重い = 金属硫化物等 |
| **光沢** | 金属 · ガラス · 真珠等 | 黄鉄鉱は金属光沢 |
| **色 · 条痕** | 粉末の色 | 条痕は色の安定指標 |
| **透明度** | 透明 · 半透明 · 不透明 | |

### 4.1 モース硬度尺度

[モース硬度](https://ja.wikipedia.org/wiki/%E3%83%A2%E3%83%BC%E3%82%B9%E7%A1%AC%E5%BA%A6): **相対硬度**（1=最軟 talc, 10=最硬 diamond）。**刻划試験** で比較する。

| 硬度 | 鉱物 | 日常の目安 |
|------|------|------------|
| 1 | 滑石 | 爪で刻める |
| 2–3 | 石膏 · 方解石 | 爪〜銅貨 |
| 4–5 | 蛍石 · リン灰石 | ナイフで刻める |
| 5–6 | 長石 · オパール | ガラスと同等 |
| 6–7 | 石英 | 鋼ファイルで刻める |
| 7+ | トパーズ · コランダム | 石英より硬い |

## 鉱物と岩石 · 環境

| 接続 | 内容 |
|------|------|
| **岩石学** | 岩石 = 鉱物の集合体 |
| **堆積学** | 粘土鉱物 · 石英砂 |
| **構造地質学** | 葉理 · 劈理と板状シリケート |
| **鉱床学** | 経済鉱物 · 鉱石 |
| **地球化学** | 元素分配 · 同位体 |

**風化**: 不安定鉱物（長石）→ 粘土鉱物 + 溶解イオン。安定鉱物（石英）が残る。

---

## 適用範囲と限界

- モース尺度は **順序尺度** であり、硬度差は線形ではない（石英 7 と ダイヤ 10 の差は実際より大きい）。
- 同定は **複数性質の組み合わせ** が原則。硬度のみでは不十分。
- 非晶質（火山ガラス）や有機物は本フェーズの「鉱物」定義外。
