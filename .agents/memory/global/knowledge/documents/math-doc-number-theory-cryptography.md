# 数論と暗号

## 整除と同余

a ≡ b (mod n)。拡張ユークリッド算法で gcd と逆元。

## 素数判定

Miller-Rabin などの確率的素性判定。

## RSA

素数 p,q、n=pq、公開 e・秘密 d で m^e mod n を暗号化。因数分解困難性に依拠。

## 不完全性定理（概観）

十分強い再帰的公理化体系は自身の無矛盾性を体系内で証明できない。
