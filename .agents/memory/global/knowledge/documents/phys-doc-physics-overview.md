# 物理学の全体像

**出典**: [物理学（Wikipedia）](https://ja.wikipedia.org/wiki/物理学) · [物理学の分野（Wikipedia）](https://ja.wikipedia.org/wiki/物理学の分野)

---

## 物理学とは

物理学（physics）は、**物質 · エネルギー · 時空** およびそれらの **相互作用** を研究する自然科学の基礎分野である。化学 · 生物学 · 工学など多くの分野の根底にある原理を提供する。

| 研究対象 | 例 |
|----------|-----|
| **物質** | 粒子 · 固体 · 流体 · プラズマ |
| **エネルギー** | 運動エネルギー · 熱 · 電磁場エネルギー |
| **時空** | 位置 · 速度 · 加速度 · 時刻 · 曲率 |
| **相互作用** | 重力 · 電磁 · 強 · 弱 |

数学と密接に結びつき、**モデル化 · 法則 · 予測 · 実験検証** が中心的方法論である。

---

## 古典 · 近代 · 現代

| 区分 | 時代感 | 代表的内容 |
|------|--------|------------|
| **古典物理学** | 17–19 世紀 | ニュートン力学 · 熱力学 · マクスウェル電磁気 |
| **近代物理学** | 20 世紀初頭 | 量子力学 · 特殊/一般相対性理論 |
| **現代物理学** | 20 世紀後半– | 素粒子 · 宇宙論 · 物性 · 量子情報 |

**境界は曖昧**: 統計力学は古典と近代の橋渡し。コンピュータシミュレーションは全分野に横断する。

## 主要分野

| 分野 | 核心概念 |
|------|----------|
| **力学** | ニュートン法則 · 保存則 · ラグランジュ/ハミルトン |
| **波動 · 振動** | 重ね合わせ · 共振 · 音波 |
| **熱力学** | 温度 · エントロピー · 状態方程式 |
| **電磁気学** | クーロン · アンペール · ファラデー · Maxwell |
| **光学** | 反射 · 屈折 · 干渉 · 回折 |
| **量子力学** | 波動関数 · 観測 · 不確定性 |
| **相対性理論** | ローレンツ変換 · 時空 · 重力 |
| **統計力学** | 分配関数 · ボルツマン · フェルミ/ボース |

分野の境界は曖昧であり、統計力学 · 光学 · 物性物理などは複数分野にまたがる。

## 物理学の方法論

1. **観察** — 現象を定量的に記録する
2. **モデル化** — 理想化（質点 · 剛体 · 理想気体など）で記述を簡約する
3. **法則の定式化** — 数学的関係（方程式 · 保存則）として表す
4. **予測** — 法則から新たな現象を導く
5. **実験検証** — 予測と観測を比較し、モデルを修正する

**次元解析 · 単位 · オーダー推定** は全分野で横断的に使う。物理量の次元が一致しない式は物理的に意味を持たない。
