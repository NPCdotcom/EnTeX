# 幾何と位相

**出典**: [数学（Wikipedia）](https://ja.wikipedia.org/wiki/数学)「空間 · 幾何学 · 位相幾何学」

---

## 1. 解析幾何（平面）

点 P = (x, y) · ベクトル OP

| 概念 | 公式 |
|------|------|
| 距離 | \|AB\| = √((x₂−x₁)² + (y₂−y₁)²) |
| 中点 | ((x₁+x₂)/2, (y₁+y₂)/2) |
| 直線 | ax + by + c = 0 または y = mx + b |
| 円 | (x−h)² + (y−k)² = r² |

**例**: A(0,0), B(3,4) → |AB| = **5**（3-4-5 三角形）

---

## 2. 三角法

| 関係 | 式 |
|------|-----|
| ピタゴラス | a² + b² = c²（直角三角形） |
| sin θ | 対辺/斜辺 |
| cos θ | 隣辺/斜辺 |
| tan θ | sin/cos |

### 加法定理

- sin(α±β) = sin α cos β ± cos α sin β
- cos(α±β) = cos α cos β ∓ sin α sin β

** 連携**: sin, cos の微分・級数展開

---

## 3. ユークリッド幾何

**公理系**（ユークリッド原論）: 点 · 直線 · 円 · 平行公理

**歴史**: 定規とコンパス作図 → ガロア理論で「三等分角·倍立方体は不可能」と判明（ 群論と接続）

---

## 4. 位相の入口

**位相空間** (X, τ): 開集合族 τ が公理を満たす

| 公理 | 内容 |
|------|------|
| ∅, X ∈ τ | |
| 任意個の和 | 開集合の任意和は開 |
| 有限個の積 | 開集合の有限共通部分は開 |

**連続写像**: 開集合の逆像が開

**直観**: 「近さ」を距離なしで記述 → 位相幾何学 · 解析学（連続関数）の橋

**例**: ℝ 上の通常位相 — 開区間 (a,b) が開集合の生成元

---

## 5. 対称性（群と幾何）

正 n 角形の **回転群** Cₙ（位数 n）
**二面体群** Dₙ: 回転 + 反射（位数 2n）

→ algebra.md の群論と対応

## 6. 演習

### 6.1 距離

(1,2) と (4,6) → √((4−1)²+(6−2)²) = √(9+16) = **5**

### 6.2 円

中心 (0,0), 半径 5 → x² + y² = 25。点 (3,4) は 9+16=25 → **円上**

### 6.3 三角法

sin 30° = **1/2**, cos 60° = **1/2**
