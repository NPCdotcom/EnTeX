# ゲーム理論とミニマックス

n 人の戦略的相互作用を数学的にモデル化する。経済学 · 進化生物学 · 計算機科学（マルチエージェント）の基礎。

---

## 1. 正規形ゲーム

- n 人プレイヤー i = 1,…,n
- 各プレイヤー i の **純粋戦略** 集合 S_i（有限）
- **利得関数** u_i: S_1 × … × S_n → ℝ

戦略プロファイル s = (s_1,…,s_n) でプレイヤー i の利得は u_i(s)。

---

## 2. 最適反応とナッシュ均衡

**最適反応** BR_i(s_{-i}) = argmax_{s_i ∈ S_i} u_i(s_i, s_{-i})

**純粋戦略ナッシュ均衡**: s* について全 i で s_i* ∈ BR_i(s*_{-i})

**例 — 囚人のジレンマ**（利得行列、行=プレイヤー1）:

|     | 協力 | 裏切 |
|-----|------|------|
| 協力 | (−1,−1) | (−3, 0) |
| 裏切 | (0,−3) | (−2,−2) |

純粋 NE: (裏切, 裏切)。どちらかが協力を変えれば利得改善可能。

---

## 3. 混合戦略

純粋均衡が存在しないゲーム（マッチングペニーズ）では **混合戦略** σ_i ∈ Δ(S_i) = {p ≥ 0 : Σ_k p_k = 1} を用いる。

**期待利得**:

ũ_i(σ) = Σ_{s ∈ S_1×…×S_n} (Π_j σ_j(s_j)) u_i(s)

**混合ナッシュ均衡**: σ* について全 i, 全 σ_i で

ũ_i(σ_i*, σ*_{-i}) ≥ ũ_i(σ_i, σ*_{-i})

**マッチングペニーズ**: 行・列とも (1/2, 1/2) が唯一の混合 NE（期待利得 0）。

---

## 4. 存在定理（Nash, 1950/51）

**定理**: 有限プレイヤー · 有限純粋戦略のゲームには **混合戦略ナッシュ均衡が少なくとも 1 つ** 存在する。

**証明の骨格**:

1. 混合戦略空間 S = Δ(S_1) × … × Δ(S_n) は **コンパクト凸**
2. 最適反応から連続写像 f: S → S を構成
3. **Brouwer 固定点定理**（または Kakutani の集合値版）で f の固定点が存在
4. 固定点 = ナッシュ均衡

**重要**: 存在は **構成的方法を与えない** — 計算可能性は別問題（`math-doc-computational-complexity-ppad`）。

---

## 5. 支持と無差別条件

混合戦略 σ の **支持** supp(σ) = {s : σ(s) > 0}。

均衡では支持上の純粋戦略は **同じ期待利得**（無差別原理）。

### 2×2 ビマトリックスの閉形式

行が両純粋戦略を使う（0 < p < 1）とき、列の混合 q は行利得の無差別から一意:

q = (R[1][1] − R[1][0]) / (R[0][0] − R[0][1] + R[1][1] − R[1][0])

同様に p を列利得から決定。**支持列挙**は一般 n 人ゲームで全支持ペアを試す手法。

---

## 6. 零和 2 人ゲームとミニマックス

u_1(s) + u_2(s) = 0（定数和を 0 に正規化）。行プレイヤーの利得行列 A だけで記述。

**ミニマックス定理**（von Neumann）:

v = max_{p ∈ Δ} min_{q ∈ Δ} p^T A q = min_{q ∈ Δ} max_{p ∈ Δ} p^T A q

v が **ゲーム値**。(p*, q*) はナッシュ均衡と一致。

**線形計画との双対性**: 行の最大化問題と列の最小化問題は LP の強双対性で結ばれる。

---

## 7. Lemke–Howson 算法

2 人一般（非零和）ビマトリックスゲームの混合均衡を求める **pivot 算法**。人工変数を導入し表形式で追跡。

- 2×2 では閉形式・支持列挙で代替可能
- 一般には **指数時間** worst case あり

---

## 8. ε-近似ナッシュ均衡

厳密 NE の代わりに、一方的改善が ε 以下:

∀i, ∀σ_i': u_i(σ_i', σ_{-i}) ≤ u_i(σ) + ε

マッチングペニーズ (0.5, 0.5) は ε = 0。(0.7, 0.3) vs 均衡 (0.5, 0.5) では行の逸脱利得 0.4 → ε-NE でない。

ゼロ和 · 2 人など特殊ケースでは ε-NE の **FPTAS** が知られる。

---

## 9. 協調ゲームと学習（接続）

協調ゲーム（Stag Hunt 等）では **ナッシュ均衡選択** が問題 — 複数 NE のうちどれに収束するかは学習規則と初期条件に依存（`math-doc-online-learning-algorithms-games` 参照）。

Global games モデルでは私的信号と閾値 τ により均衡選択が連続的に変化する。マトリクス拡張では μ パラメータが Hare/Stag 優位を切り替える（μ=−1 臨界）。
