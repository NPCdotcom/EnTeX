# 応用化学と環境化学

---

## 1. 応用化学

化学原理を **工業プロセス · 材料 · 農薬 · 医薬** などへ実装する分野。化学工学と連携。

---

## 2. マスバランスと反応器

**一般式**: 蓄積 = 流入 − 流出 + 生成 − 消費

### 完全混合槽型反応器（CSTR）定常状態
0 = Q(C_in − C_out) + V·r(C_out)

| 反応器 | 特徴 |
|--------|------|
| バッチ | 間欠 · 小規模 |
| CSTR | 完全混合 · 定常運転 |
| PFR | 活塞流 · 濃度が位置依存 |

スケールアップ — 幾何相似 · 動力相似 · 物質移動の再現

---

## 3. 環境化学の媒体

| 媒体 | 主な化学過程 |
|------|--------------|
| 大気 | 光化学スモッグ · 酸雨 · 温室効果 |
| 水圏 | 酸素消費 · 栄養塩 · 汚染物質 |
| 土壌 | 吸着 · イオン交換 · 微生物代謝 |
| 生物圏 | 生物蓄積 · 生体濃縮 |

### 箱モデル（定常）
dC/dt = E/V − kC − (Q/V)C = 0

⇒ C_ss = E / (Vk + Q)（E: 排出速度, k: 一次除去定数）

---

## 4. グリーンケミストリー

| 原則 | 内容 |
|------|------|
| 原子効率 | 副生成物を最小化 |
| 安全な溶媒 | 水 · 超臨界流体等 |
| 再生可能原料 | バイオマス由来 |
| エネルギー効率 | 温和な条件 |

---

## 5. ライフサイクルアセスメント（LCA）

製品の **原材料調達 → 製造 → 使用 → 廃棄** までの環境負荷を統合評価。単一指標（CO₂ 排出等）だけでなく多面的影響を検討する。
