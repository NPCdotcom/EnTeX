---

## 1. 組合せ論

### 1.1 基本原理

| 原理 | 内容 |
|------|------|
| **加法原理** | 互いに素な場合の数 = 各場合の和 |
| **乗法原理** | 連続する選択 = 各段階の積 |

### 1.2 順列 · 組合せ

n 個から r 個を選ぶ:

| 種類 | 公式 | 記号 |
|------|------|------|
| **順列**（順序あり） | n!/(n−r)! | nPr, P(n,r) |
| **組合せ**（順序なし） | n!/(r!(n−r)!) | nCr, C(n,r), $\binom{n}{r}$ |

**例**: 5 人から 3 人の委員会（順不同）→ C(5,3) = **10**

### 1.3 二項定理

(x + y)ⁿ = Σ_{k=0}^n C(n,k) x^{n−k} y^k

**例**: (x+y)³ = x³ + 3x²y + 3xy² + y³

### 1.4 包除原理（入口）

|A ∪ B| = |A| + |B| − |A ∩ B|

## 2. グラフ理論

**グラフ** G = (V, E): 頂点集合 V · 辺集合 E ⊆ V×V

| 概念 | 説明 |
|------|------|
| **次数** | 頂点に接する辺の数 |
| **経路** | 頂点列 v₀→v₁→…→v_k |
| **閉路** | 始点=終点の経路 |
| **木** | 連結かつ閉路なし（n 頂点 → n−1 辺） |
| **完全グラフ K_n** | 任意 2 頂点が辺で接続 |

### 最短経路（BFS）

非負重み · 単位距離 → **幅優先探索（BFS）** で最短経路長

## 3. 計算理論（入口）

| 概念 | 内容 |
|------|------|
| **チューリング機械** | テープ + 状態 + 読書/書込/移動の抽象計算モデル |
| **可算** | チューリング機械で計算可能 |

**チャーチのテーゼ**: 自然数上の「アルゴリズム的に計算可能」= チューリング可算
