## 自然地理学とは何か

[自然地理学](https://ja.wikipedia.org/wiki/%E8%87%AA%E7%84%B6%E5%9C%B0%E7%90%86%E5%AD%A6)（physical geography）は、地球表面の **自然環境** — 地形 · 気候 · 水文 · 土壌 · 植生 — を **空間的に統合** して研究する分野。地学各分科（地質学 · … · 気候学）の **地表統合層** である。

| 観点 | 内容 |
|------|------|
| **対象** | 景観 · 自然システム · 地域 |
| **問い** | なぜここはこう見えるか · 要素はどう結びつくか |
| **方法** | 野外 · 地図 · GIS · リモートセンシング |
| **成果** | 地域理解 · 土地利用 · 保全 · 災害 |

**人文地理学** との違い: 自然地理学は **自然プロセスと環境** を主題とし、人口 · 経済等は **人地関係** として接続する。

## 景観の構成要素

[景観](https://ja.wikipedia.org/wiki/%E6%99%AF%E8%A6%B3) = 自然要素と（しばしば）人為要素が組み合わさった **目に見える地表の姿**。

| 要素 | 内容 | 関連フェーズ |
|------|------|--------------|
| **地形（relief）** | 標高 · 傾斜 · 流域 | 地形学 |
| **気候** | 温度 · 降水 · 季節 | 気候学 |
| **水文** | 河川 · 湖 · 地下水 | 水文学 · 陸水学 |
| **土壌 · 地質** | 母材 · 土壌型 | 土壌学 · 地質学 · … · 岩石学 |
| **植生 · 生態系** | バイオーム | 生物学側 |
| **人為要素** | 農地 · 都市 · インフラ | 人地関係 |

## 自然地理学的アプローチ

### 3.1 空間尺度

| 尺度 | 例 |
|------|-----|
| **全球** | プレート · 気候帯 |
| **地域** | 流域 · 地方 |
| **局地** | 斜面 · 谷 · 海岸 |

### 3.2 統合の視点

```text
  岩石 · 構造 (地質学 · … · 構造地質学)
        |
  地形形成 (地形学)  <-- 気候 (気候学) --> 植生
        |                |
  堆積 · 土壌 (堆積学,土壌学)   水文 (水文学,陸水学)
        |
     景観 (自然地理学)
```

**系統地理学**: 1 要素（例: 気候）を全球で扱う。  
**地域地理学**: 1 地域内の全要素を統合する。

## 人地関係

[人地関係](https://ja.wikipedia.org/wiki/%E4%BA%BA%E5%9C%B0%E9%9B%A2%E4%BF%82): 人間活動と自然環境の **相互作用**。

| 論点 | 内容 |
|------|------|
| **自然資源** | 水 · 土壌 · 鉱物 · エネルギー |
| **災害リスク** | 地震 · 洪水 · 土砂（自然災害） |
| **土地利用** | 農業適地 · 都市立地 |
| **環境変化** | 森林減 · 砂漠化 · 気候変動（気候変動） |
| **保全** | 自然公園 · 生態系サービス |

自然地理学は **適地適所** の判断に科学的根拠を提供する。
