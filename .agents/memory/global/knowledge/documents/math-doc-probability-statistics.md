# 確率論 · 統計学

**出典**: [数学（Wikipedia）](https://ja.wikipedia.org/wiki/数学)「有限数学 · 確率論 · 統計」

---

## 1. 確率空間（直観）

**確率空間** (Ω, ℱ, P):

| 記号 | 意味 |
|------|------|
| Ω | **標本空間**（起こりうる結果全体） |
| ℱ | 事象（Ω の部分集合） |
| P | 確率測度 P: ℱ → [0,1], P(Ω)=1 |

**公理（コルモゴロフ）**:

1. P(A) ≥ 0
2. P(Ω) = 1
3. 互いに素な可算個 A_i → P(∪A_i) = Σ P(A_i)

本節では **有限標本空間** を主対象とする。

---

## 2. 基本公式

| 公式 | 式 |
|------|-----|
| 余事象 | P(Aᶜ) = 1 − P(A) |
| 和事象 | P(A ∪ B) = P(A) + P(B) − P(A ∩ B) |
| **条件付き確率** | P(A\|B) = P(A ∩ B) / P(B) （P(B)>0） |
| **乗法定理** | P(A ∩ B) = P(A\|B) P(B) |
| **ベイズ** | P(A\|B) = P(B\|A) P(A) / P(B) |
| **独立** | P(A ∩ B) = P(A) P(B) |

---

## 3. 離散確率変数

**期待値**: E[X] = Σ x P(X=x)
**分散**: Var(X) = E[(X−E[X])²] = E[X²] − (E[X])²

**例**: 公平サイコロ X

- E[X] = (1+2+3+4+5+6)/6 = **3.5**
- E[X²] = (1+4+9+16+25+36)/6 = 91/6
- Var(X) = 91/6 − (3.5)² = **35/12 ≈ 2.917**

---

## 4. 代表的分布（有限 · 入口）

| 分布 | パラメータ | P(X=k) |
|------|------------|--------|
| **ベルヌーイ** | p | P(1)=p, P(0)=1−p |
| **二項** B(n,p) | n 試行, 成功確率 p | C(n,k) p^k (1−p)^{n−k} |
| **幾何** | 成功確率 p | 初成功までの試行数 |

## 5. 演習

### 5.1 条件付き

袋に赤3·白2。1 個取り出し赤 → 2 個目も赤:
P(2回目赤|1回目赤) = 2/4 = **1/2**（非復元）

### 5.2 二項

10 回投げて表 6 回: C(10,6) (1/2)^10 = 210/1024 ≈ **0.205**

### 5.3 ベイズ（簡単）

病気率 1%, 検査感度 99%, 特異度 95%。陽性なら病気の確率:
P(D|+) = 0.99×0.01 / (0.99×0.01 + 0.05×0.99) ≈ **0.167**

## — 記述統計

**標本** x₁, …, x_n から母集団を要約する。

| 統計量 | 公式 |
|--------|------|
| **平均** x̄ | (1/n) Σ x_i |
| **分散** s² | (1/(n−1)) Σ (x_i − x̄)² |
| **標準偏差** s | √s² |
| **中央値** | 順序統計量の中央 |

**経験分布**: ヒストグラム · 箱ひげ図で形状を把握。

---

## — 推測統計（入口）

**点推定**: 標本平均 x̄ は母平均 μ の推定量
**区間推定**（正規 · σ 既知の場合）:

x̄ ± z_{α/2} · σ/√n

**例**: n=100, x̄=50, σ=10, 95% → 50 ± 1.96 → **[48.04, 51.96]**

### 仮説検定（概念）

1. **帰無仮説 H₀** · **対立仮説 H₁**
2. **検定統計量** を計算
3. **p 値**: H₀ が真なら、観測以上に極端な結果が出る確率
4. p < α なら H₀ を棄却

**例**: 公平コイン 100 回で表 60 回 — H₀: p=0.5
二項分布で p 値 ≈ 0.058（両側）→ α=0.05 なら **棄却しない**
