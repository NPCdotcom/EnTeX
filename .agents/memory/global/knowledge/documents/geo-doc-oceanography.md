## 海洋学とは何か

[海洋学](https://ja.wikipedia.org/wiki/%E6%B5%B7%E6%B4%8B%E5%AD%A6)（oceanography）は、**海洋**の物理 · 化学 · 生物 · 地質を総合的に研究する分野。地球表面の **約 71%** を占める海洋は、気候 · 水循環 · 生態系の中核である。

| 観点 | 内容 |
|------|------|
| **対象** | 海水 · 海流 · 海底 · 海洋生物 |
| **問い** | 海はどう動くか · どう変化しているか |
| **方法** | 観測ブイ · 衛星 · 潜水艇 · 数値モデル |
| **成果** | 気候予測 · 資源 · 保全 · 災害 |

| 分支 | 内容 |
|------|------|
| **物理海洋学** | 海流 · 波 · 潮汐 · 混合 |
| **化学海洋学** | 塩分 · 栄養塩 · 炭素循環 |
| **生物海洋学** | プランクトン · 食物連鎖 |
| **地質海洋学** | 海底地形 · 堆積（堆積学） |

## 海水の性質

| 性質 | 概略 |
|------|------|
| **塩分（塩分濃度）** | 平均 ~35 PSU（parts per thousand） |
| **密度** | 温度 T · 塩分 S · 圧力 P に依存 |
| **比熱** | 大きい → 気候の熱バッファ |
| **pH** | 平均 ~8.1（酸性化が課題） |

**密度の基本**: 低温 · 高塩分 → **高密度** → 鉛直安定性 · 対流の駆動。

---

## 海水の鉛直構造

| 層 | 深度（概略） | 特徴 |
|----|-------------|------|
| **表層（混合層）** | 0–100 m | 風で混合 · 季節変動 |
| **躍層（温躍層）** | 100–1000 m | 温度急減 · 安定 |
| **深層水** | >1000 m | 低温 · 均一（~2–4 C） |

**安定性**: 上の水が下より軽い（密度逆転なし）と鉛直混合は抑制される。

## 海流

[海流](https://ja.wikipedia.org/wiki/%E6%B5%B7%E6%B5%81): 海水の大規模な水平移動。

### 4.1 駆動力

| 要因 | 内容 |
|------|------|
| **風** | 表層流（表面流） |
| **密度差** | 温塩循環（熱塩循環） |
| **潮汐** | 浅海での混合 · 潮流 |
| **コリオリ力** | 北半球右偏 · 大規模環流の形成 |

### 4.2 主要海流

| 海流 | 設定 |
|------|------|
| **黒潮（Kuroshio）** | 西境界流 · 暖かい |
| **親潮** | 東境界流 · 冷たい |
| **大西洋経向回転流** | 湾流 · グリーンランド海流 |
| **南極 Circumpolar Current** | 最大規模の海流 |

**西境界流**は速く暖かい、**東境界流**は遅く冷たい傾向。

## 温塩循環

[温塩循環](https://ja.wikipedia.org/wiki/%E6%B8%A9%E7%9B%90%E5%BE%AA%E7%92%B0)（thermohaline circulation）: **温度と塩分** による密度差が駆動する全球規模の深層循環。

```text
  高緯度で海水冷却 + 氷結で塩分濃縮
       |
  高密度水が沈降（深層水形成）
       |
  海底を全球に拡散
       |
  上昇（赤道・太平洋等）-> 表層に戻る
```

| 深層水 | 形成域 |
|--------|--------|
| **北大西洋深層水（NADW）** | グリーンランド · ラブラドル海 |
| **南極底層水（AABW）** | 南極大陸周辺 |

気候変動（気候変動）で循環の弱化が議論される。

## 潮汐

[潮汐](https://ja.wikipedia.org/wiki/%E6%BD%AE%E6%B1%9A): 天体（主に月 · 太陽）の引力と慣性力による海面の周期的変動。

| 潮 | 条件 |
|----|------|
| **大潮** | 新月 · 満月（日月同相） |
| **小潮** | 上弦 · 下弦（日月直交） |

**潮汐力** ∝ 1/r^3（距離の3乗に反比例）。月の寄与が太陽より大きい。
