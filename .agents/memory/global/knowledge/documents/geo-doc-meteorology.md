## 気象学とは何か

[気象学](https://ja.wikipedia.org/wiki/%E6%B0%97%E8%B1%A1%E5%AD%A6)（meteorology）は、**短期（数時間〜数日）の大気の状態** — 天気 — とその変化を研究する分野。**気候学（気候学）** は長期平均 · 統計を扱う。

| 観点 | 内容 |
|------|------|
| **対象** | 気温 · 気圧 · 風 · 湿度 · 降水 |
| **問い** | 今どうなっているか · 明日どうなるか |
| **方法** | 地上観測 · レーダー · 衛星 · NWP |
| **成果** | 天気予報 · 防災 · 航空 · 農業 |

**天気予報（NWP）**: 数値天気予報モデルで支配方程式を離散化して未来状態を計算する。

## 観測要素

| 要素 | 単位 | 内容 |
|------|------|------|
| **気温** | C | 大気温度 |
| **気圧** | hPa | 海面換算気圧で比較 |
| **湿度** | % | 相対湿度 · 露点 |
| **風** | m/s, 方位 | 風速 · 風向 |
| **降水量** | mm | 雨 · 雪 |
| **視程 · 雲量** | | 霧 · 雲 |

**アメダス**（日本）: 自動気象観測網。レーダー · 衛星と組み合わせて予報。

## 気圧系と風

| 系 | 北半球の風（地上） | 天気傾向 |
|----|-------------------|----------|
| **高気圧** | 時計回り（反時計回りに散逸） | 晴れ · 安定 |
| **低気圧** | 反時計回り（時計回りに収束） | 雲 · 降水 |

**風の成因**: 圧力勾配力 + コリオリ力 + 摩擦力のバランス。

**等圧線**: 気圧の等高線。密なほど風が強い。

---

## 前線と気象現象

[前線](https://ja.wikipedia.org/wiki/%E5%89%8D%E7%B7%9A_(%E6%B0%97%E8%B1%A1)): 性質の異なる空気塊の境界。

| 前線 | 特徴 | 天気 |
|------|------|------|
| **寒冷前線** | 寒気が暖気の下に楔入 | 急な天気崩れ · 雷雨 |
| **温暖前線** | 暖気が寒気の上に上昇 | 広範囲の雲 · 長時間降水 |
| **停滞前線** | ほぼ静止 | 梅雨 · 長雨 |
| **閉塞前線** | 低気圧成熟 | 複雑な降水 |

**低気圧（温带サイクロン）**: 前線を伴い発達 · 移動する。

## 大気の安定度

**気温減率（lapse rate）**: 高度とともに気温が下がる率（C/km）。

| 減率 | 値（概略） | 意味 |
|------|-----------|------|
| **環境減率** | 観測値 | 実際の大気 |
| **乾燥断熱減率** | ~9.8 C/km | 上昇気塊（乾燥） |
| **湿潤断熱減率** | ~4–7 C/km | 飽和上昇 |

| 状態 | 条件 | 結果 |
|------|------|------|
| **不安定** | 環境減率 > 乾燥断熱減率 | 対流 · 積雲発達 |
| **安定** | 環境減率 < 湿潤断熱減率 | 上昇抑制 |
| **条件付き不安定** | 中間 | 雲発達に要因依存 |

**逆温層**: 高度とともに気温が上昇 → 強い安定 · 霧 · 汚染滞留。

## 降水のメカニズム

| タイプ | 内容 |
|--------|------|
| **対流性** | 積雲 · 雷雨 |
| **地形性** | 山越え上昇 |
| **前線性** | 前線に沿った上昇 |
| **台風** | 熱帯低気圧 · 強風雨 |

**露点**: 飽和に達する温度。露点に近いほど湿りやすい。

---

## 予報の限界

| 要因 | 内容 |
|------|------|
| **カオス** | 初期値誤差の増幅 |
| **解像度** | 小尺度現象の未表現 |
| **物理パラメータ化** | 雲 · 境界層の近似 |

**予報可能期間**: シノプティック尺度で ~5–7 日が実用的限界（概略）。

## 適用範囲と限界

- 風の toy は **地衡風・単純勾配** レベル。
- 台風 · メソ尺度は本フェーズでは概略のみ。
