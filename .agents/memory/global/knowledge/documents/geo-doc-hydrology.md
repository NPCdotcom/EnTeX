## 水文学とは何か

[水文学](https://ja.wikipedia.org/wiki/%E6%B0%B4%E6%96%87%E5%AD%A6)（hydrology）は、地球上の **水の循環 · 分布 · 量 · 質** を研究する分野。降水から河川 · 地下水 · 蒸発まで、**流域スケール** の物質 · エネルギー輸送が中心。

| 観点 | 内容 |
|------|------|
| **対象** | 降水 · 蒸発 · 河川 · 地下水 · 氷 |
| **問い** | どれだけ流れるか · いつ洪水か · 資源は持続するか |
| **方法** | 観測 · 水収支 · モデル · リモートセンシング |
| **成果** | 水資源 · 洪水予測 · 環境保全 |

海洋学（大洋）・地形学（侵食）・土壌学（透水）と接続する **陸上の水** のフェーズ。

---

## 水循環と流域

```text
  降水 (P)
    |
    +-- 蒸発・蒸散 (ET)
    +-- 表面流出 (Q)
    +-- 浸透 -> 地下水貯留 (dS/dt)
```

[流域](https://ja.wikipedia.org/wiki/%E6%B5%81%E5%9F%9F): 分水界で囲まれた土地。河川は **出口断面** で流量を集約する。

| 用語 | 意味 |
|------|------|
| **分水界** | 流域の境界 |
| **流域面積** | 集水範囲 (km²) |
| **径流係数** | 流出 / 降水 |
| **基礎流出** | 地下水からの恒常的寄与 |

---

## 水収支

[水収支](https://ja.wikipedia.org/wiki/%E6%B0%B4%E5%8F%8E%E6%94%AF): 流域内の水の **入出 · 貯留変化** の会計。

```text
  P = ET + Q + dS/dt + その他損失
```

| 項 | 典型スケール | 備考 |
|----|--------------|------|
| **P** 降水 | mm/yr | 気象学 気象 · 気候学 気候 |
| **ET** 蒸発散 | mm/yr | 温度 · 植生 · 土壌水分 |
| **Q** 流出 | mm/yr | 表面 + 地下 |
| **dS/dt** 貯留変化 | mm/yr | 地下水 · 土壌水 · 雪 |

**閉じた収支**: 観測誤差を除き、長期平均では dS/dt ≈ 0 となる流域が多い。

---

## 表面流出と地下水

| プロセス | 内容 |
|----------|------|
| **ホルトン流出** | 飽和超過による表面流出 |
| **ダンシー流** | 地下水の浸透流（透水係数 · 水力勾配） |
| **基礎流出** | 地下貯留から河川への遅延流出 |

```text
  強い降水 -> 急速な表面流出 (Q_peak)
  弱い降水・浸透 -> 地下水貯留 -> 長期の基礎流出
```

土壌学 土壌の **透水性** が Q の分割を決める。

## 洪水と単位過程線

[単位過程線](https://ja.wikipedia.org/wiki/%E5%8D%98%E4%BD%8D%E9%81%8E%E7%A8%8B%E7%B7%9A)（unit hydrograph, UH）: **単位降水量（例: 1 mm）** に対する **出口流量の時間応答**。

| 概念 | 内容 |
|------|------|
| **有効降雨** | 実際に流出に寄与する降水 |
| **ピーク流量** | 洪水の最大 Q |
| **遅延時間** | 降水からピークまで |
| **畳み込み** | 複数の降雨パルスを UH で合成 |

```text
  降雨 hyetograph  *  UH  =  出口 hydrograph
```

線形・時間不変の仮定は教育用 toy の前提。実流域では非線形性が大きい。

## 水文観測と応用

| 観測 | 用途 |
|------|------|
| **雨量計 · レーダー** | 降水分布 |
| **水位 · 流量計** | 河川 hydrograph |
| **井戸水位** | 地下水変動 |
| **同位体 · 化学** | 水源特定（地球化学） |

**応用**: ダム運用 · 洪水警戒 · 灌漑計画 · 都市排水 · 気候変動影響評価（気候変動）。

---

## 適用範囲と限界

- 水収支 toy は **年スケール · 均一流域** を仮定。
- UH toy は **線形 · 時間不変** の古典仮定。
- 水質 · 氷雪 · 人為取水は簡略化。

---
## 定量的モデル（水収支・単位過程線）

**流域水収支**: P = ET + Q + dS/dt（降水 = 蒸発散 + 流出 + 貯留変化）

**径流係数**: C = Q / P。湿潤森林で ~0.3–0.4、半乾燥草原で ~0.1 前後。

**単位過程線 (UH)**: 有効降雨 1 mm に対する出口流量応答。畳み込みで洪水 hydrograph を合成:
`Q_out(t) = sum_i P_eff(i) * UH(t-i)`

線形・時間不変が古典仮定。実流域では非線形性が大きい。
