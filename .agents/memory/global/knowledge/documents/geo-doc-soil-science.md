## 土壌学とは何か

[土壌学](https://ja.wikipedia.org/wiki/%E5%9C%9F%E5%A3%A4%E5%AD%A6)（soil science / pedology）は、**土壌**の生成 · 性質 · 分布 · 利用 · 保全を研究する分野。地質学の「表層」と農学 · 生態学 · 水文学（水文学）の接点である。

| 観点 | 内容 |
|------|------|
| **対象** | 土壌 · 表土 · 地下土 |
| **問い** | どうできたか · 何ができるか · どう守るか |
| **方法** | 剖面調査 · 化学分析 · 粒径 · リモートセンシング |
| **成果** | 農業 · 森林 · 防災 · 炭素貯留 · 水循環 |

**土壌の定義**: 岩石風化物 · 有機物 · 水 · 空気 · 生物が相互作用した **地表近傍の自然体**（地質学の「岩石」と区別）。

## 土壌生成（pedogenesis）

[土壌生成](https://ja.wikipedia.org/wiki/%E5%9C%9F%E5%A3%A4%E7%94%9F%E6%88%90): 母材が **物理 · 化学 · 生物** 作用を受け土壌に変化する過程。

### 2.1 形成因子（CLORPT）

| 因子 | 内容 |
|------|------|
| **C**limate | 温度 · 降水 → 風化速度 |
| **O**rganisms | 植物 · 微生物 · 動物 |
| **R**elief | 地形 · 排水 · 侵食 |
| **P**arent material | 母岩 · 母材 |
| **T**ime | 生成期間 |

### 2.2 主要プロセス

| プロセス | 内容 |
|----------|------|
| **風化** | 物理 · 化学風化（堆積学 · 地形学） |
| **淋溶** | 水による移動 · 沈殿 |
| **有機物蓄積** | 腐植質形成 |
| **酸化 · 還元** | 鉄 · マンガンの移動 |
| **粘土化** | 粘土鉱物生成 |

## 土壌断面と層序

[土壌断面](https://ja.wikipedia.org/wiki/%E5%9C%9F%E5%A3%A4%E6%96%AD%E9%9D%A2): 縦方向の **層（horizon）** の配列。

| 層 | 名称 | 特徴 |
|----|------|------|
| **O** | 有機層 | 落葉 · 腐植 |
| **A** | 表土 | 有機物混和 · 暗色 |
| **E** | 洗い出し層 | 淋溶で細粒流出（森林土等） |
| **B** | 下層土 | 沈積 · 粘土 · 鉄分富化 |
| **C** | 母材層 | 風化した母岩 |
| **R** | 岩石 | 未風化母岩 |

**土壌の厚さ** は気候 · 地形 · 時間で大きく変わる（数 cm 〜 数 m）。

## 土壌の物理性質

### 4.1 粒径组成（テクスチャー）

| 区分 | 粒径 (mm) |
|------|-----------|
| **砂** | 2.0 – 0.05 |
| **シルト** | 0.05 – 0.002 |
| **粘土** | < 0.002 |

**土壌テクスチャー**: 3 成分の比率で命名（砂質土 · 壌土 · 粘土等）。堆積学 堆積学のウエントワース尺度と接続。

### 4.2 その他

| 性質 | 内容 |
|------|------|
| **孔隙率** | 空気 · 水の貯留 |
| **透水性** | 排水 · 地下水（水文学） |
| **保水性** | 作物 · 植生 |
| **団粒構造** | 通気性 · 根張り |
