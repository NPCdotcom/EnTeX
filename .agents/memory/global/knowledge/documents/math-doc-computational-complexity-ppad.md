# PPAD と均衡計算の複雑性

## PPAD

有向グラフ上のパリティ論証に基づく複雑性クラス。

## ナッシュ均衡の計算

一般有限ゲームの均衡計算は PPAD-完全。存在は保証されるが効率算法は期待できない。

## 零和との対比

零和 2 人ゲームは線形計画で多項式時間可解。
