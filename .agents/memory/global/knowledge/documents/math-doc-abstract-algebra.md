# 抽象代数

**出典**: [数学（Wikipedia）](https://ja.wikipedia.org/wiki/数学)「構造 · 抽象代数学 · 群論」

---

## 1. 代数構造

集合 S に **演算** を定義し、公理を課す。

| 構造 | 演算 | 公理（要約） |
|------|------|--------------|
| **群** (G, ·) | 1 つの二項演算 | 結合 · 単位元 e · 逆元 |
| **環** (R, +, ×) | 2 つの演算 | (R,+) はアーベル群 · 乗法は結合 · 分配法則 |
| **体** (F, +, ×) | 2 つの演算 | 環 + 0≠1 · 乗法逆元（0 以外） |

---

## 2. 群 — 定義と例

(G, ·) が **群** ⇔

1. **結合**: (a·b)·c = a·(b·c)
2. **単位元** e: e·a = a·e = a
3. **逆元** a⁻¹: a·a⁻¹ = e

### 例

| 群 | 集合 | 演算 |
|----|------|------|
| (ℤ, +) | 整数 | 加算 |
| (ℤ/nℤ, +) | {0,…,n−1} | mod n 加算 |
| S₃ | 3 要素の置換 | 合成 |
| 正 n 角形の対称 | 回転·反射 | 合成 |

**位数**: 有限群の要素数 |G|

## 3. 対称性と幾何（ 連携）

正三角形の対称群 **D₃**（位数 6）: 3 回転 + 3 反射

群論は「対称性の共通言語」→ geometry-topology.md

## 4. 環 · 体の例

| 例 | 種類 |
|----|------|
| (ℤ, +, ×) | 環（体ではない：2 に逆元なし） |
| (ℚ, +, ×) | 体 |
| (ℝ, +, ×) | 体 |
| (ℤ/5ℤ, +, ×) | 5 は素数 → **体** |
| (ℤ/6ℤ, +, ×) | 6=2×3 → 体ではない（2,3 に逆元なし） |
