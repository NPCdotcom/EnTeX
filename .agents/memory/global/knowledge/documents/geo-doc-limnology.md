## 陸水学とは何か

[陸水学](https://ja.wikipedia.org/wiki/%E9%99%B8%E6%B0%B4%E5%AD%A6)（limnology）は、**湖沼 · 河川 · 湿地** など陸上の静止 · 緩流の淡水生態系を研究する分野。[湖沼学](https://ja.wikipedia.org/wiki/%E6%B9%96%E6%B2%BC%E5%AD%A6)はその中核で、物理 · 化学 · 生物を統合する。

| 観点 | 内容 |
|------|------|
| **対象** | 湖 · 池 · 貯水池 · 河川 · 湿地 |
| **問い** | 水質 · 生態 · 層化 · 富栄養化 |
| **方法** | プロファイル観測 · 収支 · 同定 · モデル |
| **成果** | 飲料水 · 漁業 · 生物多様性 · 環境保全 |

海洋学（塩水 · 大スケール）・水文学（流域流入）と接続する **淡水ボディ** のフェーズ。

## 湖水の層化

[湖水の層化](https://ja.wikipedia.org/wiki/%E6%B9%96%E6%B0%B4%E3%81%AE%E5%B1%A4%E5%8C%96): 密度差により鉛直混合が抑制される状態。

```text
  夏季（安定層化）:
    表層 (epilimnion)     暖 · 混合
    斜温層 (thermocline)  急温度勾配
    深層 (hypolimnion)    冷 · 孤立

  春秋（全循環 turnover）:
    表面冷却 -> 全水柱混合 -> 酸素再供給
```

| 層 | 夏季の特徴 |
|----|------------|
| **表層** | 風混合 · 光合成 · 高温 |
| **斜温層** | 密度躍層 · 混合抑制 |
| **深層** | 低酸素化リスク · 栄養塩蓄積 |

海洋学 の温塩循環と同様、**密度成層** が鉛直輸送を支配する。

## 化学 · 栄養塩 · 富栄養化

| 要素 | 役割 |
|------|------|
| **リン (P)** | 藻類増殖の制限因子（多くの淡水湖） |
| **窒素 (N)** | 共限制の場合あり |
| **溶存酸素 (DO)** | 好気生物 · 分解 |

[富栄養化](https://ja.wikipedia.org/wiki/%E5%AF%8C%E6%A0%84%E9%A4%8A%E5%8C%96): 栄養塩過多 -> 藻類ブルーム -> 酸素欠乏 · 魚類死滅。

| 状態 | 特徴 |
|------|------|
| **貧栄養 (oligotrophic)** | 低栄養 · 高透明度 |
| **中栄養 (mesotrophic)** | 中間 |
| **富栄養 (eutrophic)** | 高生産 · ブルーム |
| **超富栄養 (hypereutrophic)** | 重度ブルーム · 夏の深層無酸素 |

## 河川と湿地

| 水系 | 陸水学的観点 |
|------|--------------|
| **河川** | 連続的な物理 · 化学勾配；水文学 流出の受け皿 |
| **湿地** | 濾過 · 炭素貯留 · 生物生息地 |
| **河口域** | 淡水 - 海水混合 |

**河川 continuum 概念**: 源流から河口まで生態系が連続的に変化。

## 観測と管理

| 観測 | 内容 |
|------|------|
| **温度 · 酸素プロファイル** | 層化 · 無酸素化 |
| **透明度 (Secchi)** | 濁度 · 生産力 |
| **栄養塩 · クロロフィル** | 富栄養化指標 |
| **浮遊生物 · 底生生物** | 食物連鎖 |

**管理**: 流域負荷削減 · ダム操作 · 人工曝気 · 生物操作。
