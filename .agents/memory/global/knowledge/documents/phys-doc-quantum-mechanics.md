# 量子力学

量子力学は **原子 · 分子 · 素粒子** スケールの物理を記述する。エネルギーの量子化、波動関数による確率解釈、不確定性原理が古典力学との決定的な差である。

---

## 1. 光電効果 · プランク定数

### プランクの量子仮説

エネルギーは離散的:

E = hf = ℏω、　h ≈ 6.626×10⁻³⁴ J·s

### 光電効果

光子エネルギー hf が金属の仕事関数 φ を超えると電子が放出:

K_max = hf − φ

**閾値周波数**: f₀ = φ/h

光の粒子性を示す代表的実験である。

---

## 2. 波動関数 · シュレーディンガー方程式

### 時間独立（1 次元）

−(ℏ²/2m) d²ψ/dx² + V(x)ψ = Eψ

### ボーンの確率解釈

P(x) dx = |ψ(x)|² dx

規格化: ∫|ψ|² dx = 1

---

## 3. 1 次元無限深い井戸（粒子箱）

幅 L、V = 0（0 < x < L）、境界で ψ = 0:

ψ_n(x) = √(2/L) sin(nπx/L)、　n = 1, 2, 3, …

E_n = n²π²ℏ² / (2mL²) = n² E₁

**零点エネルギー** E₁ > 0 — 束縛された量子系の特徴。

---

## 4. 不確定性原理

位置 · 運動量:

Δx Δp ≥ ℏ/2

エネルギー · 時間（定性）:

ΔE Δt ≳ ℏ/2

同時に位置と運動量を任意精度で確定することはできない。

---

## 5. 要点

| 概念 | 内容 |
|------|------|
| 量子化 | 束縛系のエネルギー準位は離散的 |
| 波動関数 | |ψ|² が確率密度 |
| 粒子箱 | E_n ∝ n²、波長量子化 λ_n = 2L/n |
| 不確定性 | 測定精度の根本的下限 |

---

## 6. 古典との対応

巨視的スケールでは ℏ が効果的にゼロとなり、ニュートン力学が回収される（対応原理）。
